# Wave 1.5 Stage 2 — lakeFS-style Versions and Change History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dataset versions should behave like lakeFS, but through buttons and screens only (no CLI).
- **Branching:** a new draft branches from a published version *without re-uploading* (zero-copy), and several drafts can exist at once.
- **Publishing:** a draft built on an outdated base is refused. One click rebases it onto the latest version, with per-file MINE/THEIRS conflict resolution.
- **Revert:** an old version can be restored as a new draft.
- **History:** every file has a history.
- **Diff:** any two versions compare like `dvc diff` in three layers — files, data structure, metadata — with a `+2 −1 ~3` summary on every row of the version list.
- **Other:** a change note is required at publish, and every published version gets a citation (text / BibTeX / DataCite JSON).

**Architecture:**
- **Inheritance:**
  - A draft's inherited files are ordinary `catalog.dataset_files` rows that point at the *same* stored object as their source row (`inherited_from_file_id`, no `upload_session_id`).
  - Inheritance always copies from a **PUBLISHED** version. Published rows can never be deleted (DB triggers), so every shared object keeps an immutable anchor.
- **Object deletion:** decided per object, not per row.
  - A key-level advisory lock is taken.
  - The object is deleted only when **no row references it any more**.
  - The deletion itself always runs after commit.
- **Pure rules** live in a new package `apps/api/modules/catalog/versioning/`:
  - the 3-way rebase merge (`rebase.py`)
  - the three-layer diff (`diff.py`)
  - citations (`citation.py`)
  
  The services in `service/` only load rows, call those pure functions and write.
- **Schema layer of the diff:** reads the catalog's own Data Explorer column profiles (`catalog.file_previews.column_profile`, Stage 1). That profile carries types, units, missing ratios and counts — never raw values (D-018). The catalog does not import readiness internals (D-038).
- **Web:**
  - Mock mode mirrors every rule.
  - New screens: a commit-list style history tab, a draft banner with rebase and a conflict dialog, a compare screen, and a file-history panel.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 Core + Alembic, psycopg 3, pytest + testcontainers; Next.js 15, TanStack Query, openapi-fetch, MSW, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-01-research-data-portal-design.md`. Binding sections for this plan: §1 R10–R12, §3.3 (incl. "변경 내역 보기"), §3.3b, §4 rows `compareDatasetVersions` and `getDatasetCitation`, §7 "버전·변경 내역" tab, §8 row 2, §9. Existing binding rules still apply: D-012, D-013, D-018, D-029, D-038, D-039, D-040.

**Contract**

- One new error code: `DATASET_VERSION_STALE_BASE` (409, module catalog).

**Version model**
- `base_version_id`: the PUBLISHED version the draft branched from (or was rebased onto). It is set on **every** draft created while the dataset has a published version, including empty and revert drafts. It is null only for a dataset's first draft.
- `source_version_id`: the PUBLISHED version whose files the draft copied. It equals `base_version_id` for a normal draft, is an older version for a revert, and is null for an empty draft.
- `previous_version_id`: set at publish to the latest PUBLISHED version of the dataset at that moment, which the stale check forces to equal `base_version_id`. It is null for the first published version.
- After publish, all three columns are frozen by `catalog.versions_immutable()`.
- **Stale base:** publish is refused with `409 DATASET_VERSION_STALE_BASE` when `base_version_id` is not the dataset's latest PUBLISHED version, or is null while one exists. Details: `{base_version_id, latest_version_id}`. "Latest" = max `published_at`, tie-break `dataset_version_id` (the existing `repo.latest_published_version`). WITHDRAWN versions are never "latest".
- **Change note:** required at publish, 3..2000 characters after `strip()`. Otherwise `409 DATASET_VERSION_INCOMPLETE` with `details.reasons = ["CHANGE_NOTE_REQUIRED"]`.
  - Existing published versions are not touched.
  - `seed.py` publishes through `finalize_publish`, which does **not** check the note.
- **Concurrent drafts:**
  - Any number of DRAFT versions per dataset is allowed.
  - Any owner-org DATA_STEWARD may edit, rebase, publish or discard any draft of that dataset. `created_by` is shown in the UI, not enforced.
  - Two publishes of the same dataset are serialized by the existing dataset row lock in `publish_version`.

**Objects and locks**
- **Object references:** an object `(storage_bucket, storage_key)` may be referenced by many file rows.
  - Any code path that removes a row or re-points it to a new key must call `versioning.refs.release_objects(session, old_rows)` *after* the row change in the same transaction.
  - It deletes, after commit, only objects with zero remaining references.
  - The advisory lock key is `hashtextextended('catalog-object:' || bucket || '/' || key, 0)` (`pg_advisory_xact_lock`), taken in sorted `(bucket, key)` order.
- **Lock order** stays global, *version → dataset → upload session → files*:
  - publish locks the version, then the dataset;
  - rebase / discard / delete lock the version first;
  - advisory object locks come last.

**Diff, history and citation**
- **Diff file layer:**
  - Compared by `path`.
  - `CHANGED` ⇔ sha256 differs; equal sha256 is `UNCHANGED`, even when re-uploaded.
  - Order: path, byte-wise (`collate("C")` in SQL, `sorted(key=lambda p: p.encode())` in Python).
- **Diff schema layer:**
  - Only for paths present on both sides whose two `file_previews` rows are `READY`; otherwise `status: "PROFILE_MISSING"`.
  - Reported:
    - `rows: [before, after]`, using profile `total_rows` (may be null)
    - `columns_added` / `columns_removed` (names)
    - `columns_changed[]` with `type`, `unit` and `missing_ratio` pairs. `missing_ratio` only when `|Δ| ≥ 0.001`, rounded to 4 places.
  - **Never** min/max/mean/histogram/top values/preview rows (D-018).
- **Diff metadata layer:**
  - The `metadata_snapshot` of each side, flattened to dotted keys (lists and person objects compared whole). For a DRAFT side, the snapshot is built live with the same builder publish uses.
  - Output `[{field, before, after}]` sorted by field.
  - Missing keys (pre-Stage-1 snapshots) count as `null`.
- **Visibility:**
  - Diff, file history and citation follow `access.can_see_version` for every version they touch; an invisible version → `404`.
  - Citation and file history only consider PUBLISHED versions (drafts never appear in file history; citing a draft → `409 DATASET_VERSION_NOT_PUBLISHED`).
- **Citation identifiers:**
  - `{nais_public_base_url}/id/dataset-version/{version_id}` (`CatalogSettings.nais_public_base_url`)
  - NTIS numbers as DataCite `nameIdentifier` with `nameIdentifierScheme: "NTIS"`.

**Runtime and commands**

## Review Focus

1. **Deleting an inherited file from a draft must never delete the published object.** A steward branches v2 from v1, removes `data/a.csv`, then discards the draft. v1's `data/a.csv` must still download, byte for byte. The same holds for re-uploading over an inherited path. Pinned in Task 3: `test_deleting_inherited_file_keeps_published_object` and `test_reupload_over_inherited_path_keeps_old_object`.
2. **Two stewards publish two drafts of the same dataset at the same moment.** Exactly one wins. The other gets `DATASET_VERSION_STALE_BASE`, never a silently lost update and never a 500. Pinned in Task 5: `test_concurrent_publish_second_is_stale`.
3. **A rebase where both sides changed the same file is never resolved silently.** Without a resolution it returns `409 CONFLICT` listing the path and changes nothing. With `MINE`/`THEIRS` it applies exactly that choice. An identical change on both sides is not a conflict. Pinned in Task 7: `test_rebase_conflict_requires_resolution` and the pure merge table `test_three_way_table`.
4. **A revert must show up as a change, not as "nothing changed".** Reverting v3 to v1 creates a draft whose base is v3. It is not stale, and its diff against v3 lists exactly the files that differ between v1 and v3. Pinned in Task 4: `test_revert_draft_is_based_on_latest_and_shows_changes`.
5. **The schema diff must not leak values to someone without download permission.** `a.researcher` comparing two versions of Institute B's CONTROLLED dataset sees column names, types, units, missing-ratio deltas and row counts. It sees no min/max/mean/top value/histogram/preview cell. Pinned in Task 6: `test_schema_layer_has_no_raw_values`.

## Decisions taken while planning (spec gaps resolved)

- **Revert semantics.**
  - The spec says "옛 버전을 기준으로 새 초안 … rebase하면 되돌리기". With a real 3-way merge that would undo the revert, because an unchanged draft takes "theirs".
  - The plan instead creates a revert draft whose **files come from the old version (`source_version_id`) but whose base is the latest version**. It is immediately publishable, and its diff shows the revert.
  - `createDatasetVersion` gains `from_version_id` (file source, default = latest) and `empty: true` (no files, base = latest). There is no user-supplied `base_version_id` — the base is always the latest at creation.
- **Default of a new draft changes.** Wave 1 drafts started empty. From Stage 2, a new draft inherits the latest version's files unless `empty: true`. The few Wave 1 tests that create a second version and assume it is empty are updated in Task 4.
- **Schema layer source.**
  - The spec says "M05 readiness profile". Readiness stores no per-file column statistics, only check evidence. The catalog's own Stage 1 Data Explorer profile has exactly the needed non-raw fields.
  - Task 6 adds `total_rows` to that profile:
    - parquet: `metadata.num_rows`
    - csv/tsv: `rows_sampled` when not truncated, else `null`
  - Inherited files copy the source file's READY profile at publish, so no regeneration is needed (spec §3.3b "재검증 비용 없음").
- **Draft side of the schema layer.** Previews are generated after publish (Stage 1). For a draft, inherited files use their source file's profile (via `inherited_from_file_id`); newly uploaded files show `PROFILE_MISSING` ("발행 후 표시").
- **Rebase applies in place** to the same draft row. Unchanged-in-draft paths are replaced by inherited copies of the latest version's rows; draft-owned uploads stay untouched. The draft's own objects are therefore never shared with another row, which keeps the object-reference rule simple.
- **A rebase with an open upload session** (PENDING rows in an OPEN, unexpired session) is refused with `409 CONFLICT` ("업로드 중에는 갱신할 수 없습니다").
- **Rebase conflict payload** reuses `CONFLICT` (409) with:
  - `details.conflicts = [{path, base, mine, theirs}]`, each side `{sha256, size_bytes} | null`
  - `details.latest_version_id`

  Unknown resolution paths (paths that are not conflicts) → `422 VALIDATION_FAILED` reason `UNKNOWN_PATH`.
- **Discarding a draft** (`DELETE /dataset-versions/{id}`, `discardDatasetVersion`) is new. It aborts open multipart uploads, deletes the draft's sessions, files and version, and releases objects.
- **`updateDatasetVersion`** (`PATCH /dataset-versions/{id}`, DRAFT only, body `{change_note}`) is new, so the publish dialog can save a required note.
- **Version-number guidance (R12)** is a pure web helper. From the latest label `v?MAJOR.MINOR(.PATCH)?` it suggests `vM.(m+1)` ("작은 수정") and `v(M+1).0` ("큰 변경"); non-numeric labels get no suggestion. The server keeps accepting any label matching the existing pattern.
- **Old-version download UX (R12):**
  - every row of the history has a download action (existing `?download=1` flow);
  - an old version's page shows a "최신 버전이 아닙니다 → vX" banner.
- **`change_summary`** on every `DatasetVersion` compares against `base_version_id` for a DRAFT and against `previous_version_id` for a PUBLISHED or WITHDRAWN version (null when there is no target). Computed per request in batch; nothing is stored.
- **No new events or audit actions.** Draft lifecycle (create, rebase, discard) stays unaudited as in Wave 1. Publish keeps `catalog.dataset.version_published.v1` unchanged.
- **Decision log:** `D-041` records the zero-copy reference rule, the revert semantics and the schema-layer source (Task 9).

```python
Revision ID: catalog_0004
Revises: catalog_0003

from sqlalchemy.dialects.postgresql import UUID

down_revision = "catalog_0003"
branch_labels = None
depends_on = None

CREATE OR REPLACE FUNCTION catalog.versions_immutable() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  IF TG_OP = 'DELETE' THEN
    IF OLD.status <> 'DRAFT' THEN
      RAISE EXCEPTION 'dataset version % is % and immutable', OLD.dataset_version_id, OLD.status
        USING ERRCODE = 'integrity_constraint_violation';
    END IF;
    RETURN OLD;
  END IF;
  IF OLD.status = 'PUBLISHED' THEN
    IF NEW.status = 'WITHDRAWN' AND
       (NEW.dataset_version_id, NEW.dataset_id, NEW.version_label, NEW.change_note, NEW.file_count,
        NEW.total_bytes, NEW.manifest_sha256, NEW.metadata_snapshot, NEW.published_at, NEW.published_by,
        NEW.created_by, NEW.created_at, NEW.base_version_id, NEW.source_version_id, NEW.previous_version_id)

        OLD.created_by, OLD.created_at, OLD.base_version_id, OLD.source_version_id, OLD.previous_version_id) THEN
```

```python
"""Stored-object references (spec §3.3b). Several file rows may share one object (zero-copy drafts); an object is
deleted only after commit and only when no row references it any more.

Why this is enough: rows are only ever *copied* from PUBLISHED versions, whose rows can never be deleted
(catalog.files_immutable / versions_immutable). An object shared with a published row therefore always keeps a
reference. The advisory lock serializes two transactions that remove the last two references at the same time."""

from collections.abc import Iterable, Mapping, Sequence
from typing import Any

from sqlalchemy import exists, select, text
from sqlalchemy.orm import Session

from api.modules.catalog.service.uploads import StorageCleanup, cleanup_target
from api.modules.catalog.tables import dataset_files


def lock_objects(session: Session, objects: Iterable[tuple[str, str]]) -> None:
    """Transaction-scoped locks in sorted order (no deadlock between two releasers)."""
    for bucket, key in sorted(set(objects)):
        session.execute(
            text("SELECT pg_advisory_xact_lock(hashtextextended(:k, 0))"),
            {"k": f"catalog-object:{bucket}/{key}"},
        )


def release_objects(session: Session, old_rows: Sequence[Mapping[str, Any]]) -> list[StorageCleanup]:
    """Call after `old_rows` were deleted or re-pointed in this transaction."""
    by_object = {(r["storage_bucket"], r["storage_key"]): r for r in old_rows}
    lock_objects(session, by_object)
    cleanups: list[StorageCleanup] = []
    for (bucket, key), row in sorted(by_object.items()):
        referenced = session.execute(
            select(
                exists().where(dataset_files.c.storage_bucket == bucket, dataset_files.c.storage_key == key)
            )
        ).scalar_one()
        if not referenced:
            cleanups.append(cleanup_target(row))
    return cleanups
```

```python
"""Zero-copy inheritance (spec §3.3b): a draft's files point at the source version's stored objects."""

from datetime import datetime
from uuid import UUID

from sqlalchemy import insert, select
from sqlalchemy.orm import Session

from api.modules.catalog.tables import dataset_files
from api.platform.ids import new_id

COPIED = (
    "path", "size_bytes", "sha256", "media_type", "storage_bucket", "storage_key", "scan_status", "verified_at",
)


def copy_rows(session: Session, source_rows: list[dict[str, object]] | list, *, to_version_id: UUID, now: datetime) -> int:
    """Insert one inherited row per source row (status VERIFIED, no session, same object)."""
    values = [
        {
            **{c: src[c] for c in COPIED},
            "file_id": new_id(),
            "dataset_version_id": to_version_id,
            "upload_session_id": None,
            "inherited_from_file_id": src["file_id"],
            "multipart_upload_id": None,
            "part_size_bytes": None,
            "status": "VERIFIED",
            "failure_code": None,
            "created_at": now,
            "updated_at": now,
        }
        for src in source_rows
    ]
    if values:
        session.execute(insert(dataset_files), values)
    return len(values)


def copy_files(session: Session, *, from_version_id: UUID, to_version_id: UUID, now: datetime) -> int:
    source = session.execute(
        select(dataset_files).where(dataset_files.c.dataset_version_id == from_version_id)
    ).mappings().all()
    return copy_rows(session, list(source), to_version_id=to_version_id, now=now)
```

```python
def inherit_previews(session: Session, version_id: UUID) -> int:
    """Inherited files are the same object as their source: reuse its finished profile (spec §3.3b)."""
    src = file_previews.alias("src")
    result = session.execute(
        pg_insert(file_previews)
        .from_select(
            [c.name for c in file_previews.c],
            select(
                *[
                    dataset_files.c.file_id if c.name == "file_id" else src.c[c.name]
                    for c in file_previews.c
                ]
            )
            .select_from(dataset_files.join(src, src.c.file_id == dataset_files.c.inherited_from_file_id))
            .where(dataset_files.c.dataset_version_id == version_id, src.c.status != "PENDING"),
        )
        .on_conflict_do_nothing(index_elements=["file_id"])
    )
    return rowcount(result)
```

```python
"""Three-layer version comparison (spec §3.3 "변경 내역 보기"). Pure; never returns raw data values (D-018)."""

from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from typing import Any

MISSING_RATIO_EPSILON = 0.001
# Person blocks and lists are compared whole; nested organization dicts inside a person stay inside it.
WHOLE_KEYS = frozenset({"people.principal_investigator", "people.steward_contact", "people.contributors"})


@dataclass(frozen=True)
class FileEntry:
    path: str
    size_bytes: int
    sha256: str


def _side(e: FileEntry | None) -> dict[str, Any] | None:
    return None if e is None else {"size_bytes": e.size_bytes, "sha256": e.sha256}


def diff_files(before: Mapping[str, FileEntry], after: Mapping[str, FileEntry]) -> list[dict[str, Any]]:
    out: list[dict[str, Any]] = []
    for path in sorted(set(before) | set(after), key=lambda p: p.encode("utf-8")):
        b, a = before.get(path), after.get(path)
        if b is None:
            status = "ADDED"
        elif a is None:
            status = "REMOVED"
        elif a.sha256 != b.sha256:
            status = "CHANGED"
        else:
            status = "UNCHANGED"
        size_delta = (a.size_bytes if a else 0) - (b.size_bytes if b else 0)
        out.append({"path": path, "status": status, "before": _side(b), "after": _side(a), "size_delta": size_delta})
    return out


def summarize(changes: Sequence[Mapping[str, Any]]) -> dict[str, int]:
    counts = {"added": 0, "removed": 0, "changed": 0, "unchanged": 0}
    for c in changes:
        counts[str(c["status"]).lower()] += 1
    return counts


def _pair(b: Any, a: Any) -> list[Any] | None:
    return None if b == a else [b, a]


def diff_schema(path: str, before: Mapping[str, Any] | None, after: Mapping[str, Any] | None) -> dict[str, Any]:
    if before is None or after is None:
        return {"path": path, "status": "PROFILE_MISSING"}
    bcols = {c["name"]: c for c in before.get("columns", [])}
    acols = {c["name"]: c for c in after.get("columns", [])}
    changed: list[dict[str, Any]] = []
    for name in [n for n in acols if n in bcols]:
        b, a = bcols[name], acols[name]
        ratio: list[float] | None = None
        if abs(float(a["missing_ratio"]) - float(b["missing_ratio"])) >= MISSING_RATIO_EPSILON:
            ratio = [round(float(b["missing_ratio"]), 4), round(float(a["missing_ratio"]), 4)]
        entry = {"name": name, "type": _pair(b.get("type"), a.get("type")),
                 "unit": _pair(b.get("unit"), a.get("unit")), "missing_ratio": ratio}
        if entry["type"] or entry["unit"] or entry["missing_ratio"]:
            changed.append(entry)
    return {
        "path": path,
        "status": "COMPARED",
        "rows": [before.get("total_rows"), after.get("total_rows")],
        "columns_added": [n for n in acols if n not in bcols],
        "columns_removed": [n for n in bcols if n not in acols],
        "columns_changed": changed,
    }


def flatten(snapshot: Mapping[str, Any] | None, prefix: str = "") -> dict[str, Any]:
    out: dict[str, Any] = {}
    for key, value in (snapshot or {}).items():
        dotted = f"{prefix}{key}"
        if isinstance(value, Mapping) and dotted not in WHOLE_KEYS:
            out.update(flatten(value, f"{dotted}."))
        else:
            out[dotted] = value
    return out


def diff_metadata(before: Mapping[str, Any] | None, after: Mapping[str, Any] | None) -> list[dict[str, Any]]:
    b, a = flatten(before), flatten(after)
    return [
        {"field": key, "before": b.get(key), "after": a.get(key)}
        for key in sorted(set(b) | set(a))
        if b.get(key) != a.get(key)
    ]
```

```python
"""compareDatasetVersions (spec §3.3) and per-version change summaries."""

from collections.abc import Mapping, Sequence
from typing import Any
from uuid import UUID

from sqlalchemy import select
from sqlalchemy.engine import RowMapping
from sqlalchemy.orm import Session

from api.modules.catalog.access import can_see_version, not_found
from api.modules.catalog.deps import CatalogDeps
from api.modules.catalog.repo import files_of_versions, load_dataset, load_version, must

from api.modules.catalog.versioning.diff import FileEntry, diff_files, diff_metadata, diff_schema, summarize
from api.platform.auth import CurrentUser
from api.platform.errors import ApiError
from api.platform.generated.error_codes import ErrorCode

TABULAR = (".csv", ".tsv", ".parquet")


def default_target(version: Mapping[Any, Any]) -> UUID | None:
    return version["base_version_id"] if version["status"] == "DRAFT" else version["previous_version_id"]


def _entries(files: Sequence[Mapping[Any, Any]]) -> dict[str, FileEntry]:
    return {f["path"]: FileEntry(f["path"], int(f["size_bytes"]), f["sha256"].strip()) for f in files}


def summaries(session: Session, versions: Sequence[Mapping[Any, Any]]) -> dict[UUID, dict[str, int] | None]:
    targets = {v["dataset_version_id"]: default_target(v) for v in versions}
    ids = list({*targets, *(t for t in targets.values() if t is not None)})
    files = files_of_versions(session, ids)
    return {
        vid: summarize(diff_files(_entries(files[t]) if t else {}, _entries(files[vid])))
        for vid, t in targets.items()
    }


def _profiles(session: Session, files: Sequence[Mapping[Any, Any]]) -> dict[str, dict[str, Any]]:
    """Profile per path; an inherited draft row uses its source row's profile (same object)."""
    key = {f["file_id"]: f.get("inherited_from_file_id") or f["file_id"] for f in files}
    found = {
        r.file_id: r.column_profile
        for r in session.execute(
            select(file_previews.c.file_id, file_previews.c.column_profile).where(
                file_previews.c.file_id.in_(list(set(key.values()))), file_previews.c.status == "READY"
            )
        )
    }
    return {f["path"]: found[key[f["file_id"]]] for f in files if key[f["file_id"]] in found}


def compare(session: Session, deps: CatalogDeps, user: CurrentUser, version_id: UUID, against: UUID | None) -> dict[str, Any]:
    version = load_version(session, version_id)
    ds = load_dataset(session, version["dataset_id"]) if version else None
    if version is None or ds is None or not can_see_version(user, ds, version):
        raise not_found("Dataset version")
    target_id = against if against is not None else default_target(version)
    target = load_version(session, target_id) if target_id else None
    if target_id is not None:
        target_ds = load_dataset(session, target["dataset_id"]) if target else None
        if target is None or target_ds is None or not can_see_version(user, target_ds, target):
            raise not_found("Dataset version")  # never reveal versions the caller cannot see
        if target["dataset_id"] != ds["dataset_id"]:
            raise ApiError(ErrorCode.VALIDATION_FAILED, "Both versions must belong to the same dataset.",
                           {"fields": [{"field": "against", "reason": "DIFFERENT_DATASET"}]})
    files = files_of_versions(session, [version_id, *([target_id] if target_id else [])])
    after_files, before_files = files[version_id], (files[target_id] if target_id else [])
    changes = diff_files(_entries(before_files), _entries(after_files))
    before_profiles, after_profiles = _profiles(session, before_files), _profiles(session, after_files)
    schema = [
        diff_schema(c["path"], before_profiles.get(c["path"]), after_profiles.get(c["path"]))
        for c in changes
        if c["status"] == "CHANGED" and c["path"].lower().endswith(TABULAR)
    ]
    return {
        "from_version_id": target_id,
        "to_version_id": version_id,
        "summary": summarize(changes),
        "files": changes,
        "schema": schema,
        "metadata": diff_metadata(_snapshot(session, deps, target, ds), _snapshot(session, deps, version, ds)),
    }
```

```python
"""3-way rebase of a draft onto the latest published version (spec §3.3b). Pure. Sides map path -> sha256."""

from collections.abc import Mapping
from dataclasses import dataclass


@dataclass(frozen=True)
class Conflict:
    path: str
    base: str | None
    mine: str | None
    theirs: str | None


@dataclass(frozen=True)
class RebasePlan:
    take_theirs: tuple[str, ...]
    keep_mine: tuple[str, ...]
    conflicts: tuple[Conflict, ...]


def three_way(
    base: Mapping[str, str], mine: Mapping[str, str], theirs: Mapping[str, str], resolutions: Mapping[str, str]
) -> RebasePlan:
    take: list[str] = []
    keep: list[str] = []
    conflicts: list[Conflict] = []
    conflict_paths: set[str] = set()
    for path in sorted(set(base) | set(mine) | set(theirs), key=lambda p: p.encode("utf-8")):
        b, m, t = base.get(path), mine.get(path), theirs.get(path)
        if m == b:
            if t != b:
                take.append(path)
        elif t == b or m == t:
            keep.append(path)
        else:
            conflict_paths.add(path)
            choice = resolutions.get(path)
            if choice == "THEIRS":
                take.append(path)
            elif choice == "MINE":
                keep.append(path)
            else:
                conflicts.append(Conflict(path, b, m, t))
    unknown = sorted(set(resolutions) - conflict_paths)
    if unknown:
        raise ValueError("UNKNOWN_PATH: " + ", ".join(unknown))
    return RebasePlan(tuple(take), tuple(keep), tuple(conflicts))
```

```python
"""rebaseDatasetVersion (spec §3.3b): re-apply a draft's changes on the latest PUBLISHED version, in place."""

from typing import Any
from uuid import UUID

from sqlalchemy import delete, select, update
from sqlalchemy.orm import Session

from api.modules.catalog.access import require_draft, steward_version
from api.modules.catalog.deps import CatalogDeps
from api.modules.catalog.repo import files_of_versions, latest_published_version, load_dataset, load_version, must
from api.modules.catalog.schemas import RebaseIn
from api.modules.catalog.service.versions import version_response
from api.modules.catalog.tables import dataset_files, dataset_versions, upload_sessions
from api.modules.catalog.versioning.inherit import copy_rows
from api.modules.catalog.versioning.rebase import three_way
from api.modules.catalog.versioning.refs import StorageCleanup, release_objects
from api.platform import clock
from api.platform.auth import CurrentUser
from api.platform.errors import ApiError
from api.platform.generated.error_codes import ErrorCode


def _side(rows: list[Any]) -> dict[str, str]:
    return {r["path"]: r["sha256"].strip() for r in rows}


def _file(row: Any | None) -> dict[str, Any] | None:
    return None if row is None else {"sha256": row["sha256"].strip(), "size_bytes": int(row["size_bytes"])}


def rebase(session: Session, deps: CatalogDeps, user: CurrentUser, version_id: UUID, body: RebaseIn
           ) -> tuple[dict[str, Any], list[StorageCleanup]]:
    version, ds = steward_version(session, user, version_id, for_update=True)  # lock order: version first
    require_draft(version)
    must(load_dataset(session, ds["dataset_id"], for_update=True), "dataset")  # then dataset: no publish meanwhile
    latest = latest_published_version(session, ds["dataset_id"])
    latest_id = latest["dataset_version_id"] if latest else None
    if version["base_version_id"] == latest_id:
        return version_response(session, version), []
    now = clock.now()
    open_upload = session.execute(
        select(upload_sessions.c.upload_session_id).where(
            upload_sessions.c.dataset_version_id == version_id,
            upload_sessions.c.status == "OPEN",
            upload_sessions.c.expires_at > now,
        ).limit(1)
    ).first()
    if open_upload is not None:
        raise ApiError(ErrorCode.CONFLICT, "Finish or cancel the open upload before updating the draft.")
    base_id = version["base_version_id"]
    ids = [version_id, *(x for x in (base_id, latest_id) if x is not None)]
    files = files_of_versions(session, ids)
    mine_rows = {r["path"]: r for r in files[version_id]}
    base_rows = {r["path"]: r for r in files[base_id]} if base_id else {}
    theirs_rows = {r["path"]: r for r in files[latest_id]} if latest_id else {}
    try:
        plan = three_way(_side(list(base_rows.values())), _side(list(mine_rows.values())),
                         _side(list(theirs_rows.values())), body.resolutions)
    except ValueError as exc:
        paths = str(exc).removeprefix("UNKNOWN_PATH: ").split(", ")
        raise ApiError(ErrorCode.VALIDATION_FAILED, "Resolutions name paths that are not in conflict.",
                       {"fields": [{"field": "resolutions", "reason": "UNKNOWN_PATH", "paths": paths}]}) from exc
    if plan.conflicts:
        raise ApiError(ErrorCode.CONFLICT, "Some files changed in both the draft and the latest version.", {
            "latest_version_id": str(latest_id),
            "conflicts": [
                {"path": c.path, "base": _file(base_rows.get(c.path)), "mine": _file(mine_rows.get(c.path)),
                 "theirs": _file(theirs_rows.get(c.path))}
                for c in plan.conflicts
            ],
        })
    replaced = [mine_rows[p] for p in plan.take_theirs if p in mine_rows]
    if replaced:
        session.execute(delete(dataset_files).where(dataset_files.c.file_id.in_([r["file_id"] for r in replaced])))
    copy_rows(session, [theirs_rows[p] for p in plan.take_theirs if p in theirs_rows], to_version_id=version_id, now=now)
    session.execute(
        update(dataset_versions).where(dataset_versions.c.dataset_version_id == version_id)
        .values(base_version_id=latest_id, updated_at=now)
    )
    cleanups = release_objects(session, replaced)
    return version_response(session, must(load_version(session, version_id), "version")), cleanups
```

```python
"""Dataset version citations (spec §4 getDatasetCitation): text (APA-like), BibTeX, DataCite 4.5 JSON. Pure."""

import json
import re
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

CREATOR_ROLES = frozenset({"CO_INVESTIGATOR"})  # PI first, then co-investigators (DataCite creators)


@dataclass(frozen=True)
class Creator:
    name: str
    affiliation: str | None
    ntis: str | None


@dataclass(frozen=True)
class CitationInput:
    title: str
    version_label: str
    year: int
    publisher: str
    uri: str
    doi: str | None
    license: str | None
    creators: tuple[Creator, ...]


def _person(p: Mapping[str, Any]) -> Creator:
    return Creator(str(p["display_name"]), (p.get("affiliation") or {}).get("name"), p.get("national_researcher_number"))


def creators_from_snapshot(snapshot: Mapping[str, Any], fallback_org: str) -> tuple[Creator, ...]:
    people = snapshot.get("people") or {}
    out: list[Creator] = []
    if people.get("principal_investigator"):
        out.append(_person(people["principal_investigator"]))
    out += [_person(c) for c in people.get("contributors") or [] if c.get("role") in CREATOR_ROLES]
    return tuple(out) or (Creator(fallback_org, None, None),)


def _bib(value: str) -> str:
    return re.sub(r"([{}&%$#_])", r"\\\1", value)


def render(style: str, c: CitationInput) -> str:
    names = ", ".join(x.name for x in c.creators)
    link = f"https://doi.org/{c.doi}" if c.doi else c.uri
    if style == "text":
        return f"{names} ({c.year}). {c.title} (Version {c.version_label}) [Data set]. {c.publisher}. {link}"
    if style == "bibtex":
        key = "nais_" + re.sub(r"[^A-Za-z0-9]", "", c.uri.rsplit("/", 1)[-1])[:32]
        fields = [
            ("author", " and ".join(_bib(x.name) for x in c.creators)),
            ("title", _bib(c.title)),
            ("version", _bib(c.version_label)),
            ("publisher", _bib(c.publisher)),
            ("year", str(c.year)),
            ("url", c.uri),
        ] + ([("doi", c.doi)] if c.doi else [])
        return "@misc{" + key + ",\n" + "".join(f"  {k} = {{{v}}},\n" for k, v in fields) + "}"
    if style == "datacite-json":
        creators = []
        for x in c.creators:
            item: dict[str, Any] = {"name": x.name, "nameType": "Personal" if x.affiliation else "Organizational"}
            if x.affiliation:
                item["affiliation"] = [{"name": x.affiliation}]
            if x.ntis:
                item["nameIdentifiers"] = [{"nameIdentifier": x.ntis, "nameIdentifierScheme": "NTIS"}]
            creators.append(item)
        data: dict[str, Any] = {
            "creators": creators,
            "titles": [{"title": c.title}],
            "publisher": {"name": c.publisher},
            "publicationYear": str(c.year),
            "version": c.version_label,
            "types": {"resourceTypeGeneral": "Dataset"},
            "identifiers": [{"identifier": c.uri, "identifierType": "URL"}]
            + ([{"identifier": c.doi, "identifierType": "DOI"}] if c.doi else []),
            "rightsList": [{"rights": c.license}] if c.license else [],
        }
        return json.dumps(data, ensure_ascii=False, sort_keys=True)
    raise ValueError(style)
```

```python
def file_history(session: Session, user: CurrentUser, dataset_id: UUID, path: str) -> dict[str, Any]:
    ds = visible_dataset(session, user, dataset_id)
    stmt = select(dataset_versions).where(
        dataset_versions.c.dataset_id == dataset_id, dataset_versions.c.status.in_(("PUBLISHED", "WITHDRAWN"))
    ).order_by(dataset_versions.c.published_at, dataset_versions.c.dataset_version_id)
    versions = [v for v in session.execute(stmt).mappings() if can_see_version(user, ds, v)]
    rows = {
        r.dataset_version_id: r
        for r in session.execute(
            select(dataset_files.c.dataset_version_id, dataset_files.c.sha256, dataset_files.c.size_bytes).where(
                dataset_files.c.dataset_version_id.in_([v["dataset_version_id"] for v in versions]),
                dataset_files.c.path == path,
            )
        )
    }
    items: list[dict[str, Any]] = []
    previous: str | None = None
    for v in versions:
        row = rows.get(v["dataset_version_id"])
        sha = row.sha256.strip() if row else None
        if sha is None:
            state = "REMOVED" if previous is not None else "ABSENT"
        elif previous is None:
            state = "ADDED"
        else:
            state = "UNCHANGED" if sha == previous else "CHANGED"
        items.append({"dataset_version_id": v["dataset_version_id"], "version_label": v["version_label"],
                      "published_at": v["published_at"], "state": state, "sha256": sha,
                      "size_bytes": int(row.size_bytes) if row else None})
        previous = sha
    return {"dataset_id": dataset_id, "path": path, "items": items}
```

```ts
/** R12 version-number guidance: small change -> next minor, big change -> next major. Labels are free text. */
export function suggestNextLabels(latest: string | null): { minor: string; major: string } | null {
  if (latest === null) return { minor: "v1.0", major: "v1.0" };
  const m = /^(v?)(\d+)(?:\.(\d+))?(?:\.\d+)?$/.exec(latest);
  if (!m) return null;
  const [, prefix, major, minor] = m;
  return { minor: `${prefix}${major}.${Number(minor ?? 0) + 1}`, major: `${prefix}${Number(major) + 1}.0` };
}
```
