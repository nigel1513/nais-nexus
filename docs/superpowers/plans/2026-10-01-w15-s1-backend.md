# Wave 1.5 Stage 1 — Research Metadata (Backend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every dataset structured, machine-readable research metadata — principal investigator, steward contact and contributors (registered users, with their affiliation *at the time*), NTIS 국가연구자번호, a one-line `subtitle`, research context, data period, collecting organization and controlled-vocabulary subjects/materials/methods. Persons can move between institutes without breaking history. Stage 1 also adds:
- a JSON-LD export;
- search filters for period, subject and collecting organization;
- a `metadata_changed` event that the future M11 index will consume;
- the **Data Explorer backend** for the Kaggle-style Data Card: per tabular file, a column profile (visible with the metadata) and a value-bearing preview (download permission only), generated after publish under bounded limits.

**Architecture:**
- **M01 identity**
  - Gains `users.national_researcher_number` plus a membership *history* (`started_at`/`ended_at`). "Current membership" now means `ended_at IS NULL`, and every identity query joins only the current one.
  - `updateMe` sets the NTIS number.
  - `transferUserOrganization` (PLATFORM_ADMIN) ends the old membership, opens a new one, and updates the Keycloak `org_code` attribute through a new `KeycloakAdminPort` before the DB transaction commits.
- **M03 catalog**
  - Gains a `vocabulary_terms` table (seeded in the migration), research columns on `datasets` (incl. `*_org_id` "at-the-time" affiliation columns) and a `dataset_contributors` table.
  - The existing `OrganizationLookup` seam grows `get_people()` / `get_email()`, so the catalog keeps reading persons only through M01's public `IdentityQueryPort`.
  - Search moves to mapping `nais-datasets-v2` (`INDEX_VERSION = 2`) and is rebuilt with the existing `reindex_all`.
  - Data Explorer:
    - Publishing a version inserts one `catalog.file_previews` row (status `PENDING`) per tabular file, in the same transaction.
    - A 10 s scheduler job leases pending rows and sends `catalog.generate_preview` actor messages.
    - The actor reads the object through the bounded readers that move from M05 into `api.platform.bounded_io` (`RangeReader`, capped raw reader, bounded line iterator). It writes `column_profile` and `preview`.
    - `getFileProfile` follows metadata visibility. `getFilePreview` additionally needs download permission (D-018: raw values are never shown without it).

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 Core + Alembic, psycopg 3, httpx (OpenSearch + Keycloak admin REST), Dramatiq, pytest + testcontainers, OpenSearch 2.19.

**Spec:** `docs/superpowers/specs/2026-10-01-research-data-portal-design.md` (binding for Stage 1: §1 decisions 1–10, §2, §3.0, §3.0b, §3.1, §3.2, §4 rows for Stage 1, §5 `metadata_changed`/`user.updated`, §6, §9). The contracts in `NAIS_PRD/contracts/` win once Task 1 has changed them. Existing binding rules still apply: D-012, D-013, D-029, D-038, D-039, D-040.

**Companion plan:** `docs/superpowers/plans/2026-10-01-w15-s1-web.md` (M10). It depends **only on Task 1** of this plan.

**Out of scope (Stages 2–4):**
- version diff, citation, mandatory `change_note`, `previous_version_id`
- file roles, processing steps, lineage, raw rules
- inquiries and the `DATASET_INQUIRY_*` notifications
- the "담당자 재지정 필요" *notification*. Stage 1 exposes `people.steward_contact_absent` and the web shows the notice. The notification ships with Stage 4, together with the other new notification types.
- lakeFS-style versioning (spec §3.3b: zero-copy drafts, rebase, revert, file history) — Stage 2. The Data Explorer keys previews by `file_id`. Stage 2's inherited files reuse the same object and can then share the profile by `(storage_bucket, storage_key)`; this plan does not implement that sharing.
- view/download counters in the activity summary (Stage 1 shows version count and last publish only — web).

**Contract and events**
- Contract version `1.3.0`. Every new secured operation declares `"401": { $ref: "#/components/responses/Error" }`.
- New `Dataset` response fields are **optional** in the schema (so Wave 1 mocks stay valid until the web plan lands); the server always sends them.
- `DatasetCreate.principal_investigator_id` and `DatasetCreate.data_steward_contact_id` are **required**.
- Events (exact):
  - produced: `identity.user.updated.v1` (payload `{user_id, organization_id, changed_fields[]}`), `catalog.dataset.metadata_changed.v1` (payload `{dataset_id, owner_organization_id, changed_fields[]}`; `changed_fields` sorted, minItems 1).
  - The transfer emits the existing `identity.membership.changed.v1` twice: old membership → DISABLED, new → ACTIVE.
- Audit:
  - `catalog.dataset.metadata_changed.v1` → new AuditAction `DATASET_UPDATED` (resource DATASET, owner `owner_organization_id`).
  - `identity.user.updated.v1` is in `NOT_AUDITED` (profile self-service, no admin action).
- No new error codes in Stage 1. Field problems are `422 VALIDATION_FAILED` with `details.fields[{field, reason}]`, using these reasons:
  - `PERSON_NOT_ELIGIBLE` — PI/steward not an ACTIVE current member of the owner org; contributor not ACTIVE
  - `VOCABULARY_TERM_UNKNOWN`
  - `TEMPORAL_RANGE` — end < start, or `temporal_from` > `temporal_to`
  - `UNKNOWN_ORGANIZATION`
  - `MUTUALLY_EXCLUSIVE` — `collecting_organization_id` + `collecting_organization_name`
  - `INVALID_FORMAT` — NTIS not `^[0-9]{8}$`
  - `DUPLICATE` — contributor (user_id, role) twice
- A duplicate NTIS number is `409 CONFLICT` with details `{field: "national_researcher_number"}`.

**Identity rules**
- **Current membership:** at most one per user (`UNIQUE (user_id) WHERE ended_at IS NULL`). Every read that joins `organization_memberships` adds `memberships.c.ended_at.is_(None)` — through the helper `CURRENT_MEMBERSHIP` in `apps/api/modules/identity/tables.py` — except the history listing.
- **Keycloak update ordering:** the DB rows are written first, then `KeycloakAdminPort.set_org_code()`. On `KeycloakAdminUnavailable` the request raises `503 DEPENDENCY_UNAVAILABLE` and the transaction rolls back.
- **Transfer idempotency:** transferring to the org the user already currently belongs to only re-asserts the Keycloak attribute and returns 200 (no new rows, no events).

**Catalog people, vocabulary and JSON-LD**
- **At-the-time affiliation:** whenever a person is assigned, the person's *current* organization id is stored next to them (`principal_investigator_org_id`, `data_steward_contact_org_id`, `dataset_contributors.affiliation_organization_id`). Re-saving an unchanged assignment never rewrites the stored affiliation.
- **Steward email exposure:** `people.steward_contact.email` is present only when `contact_email_public = true`. No other person's email ever appears in an API response.
- **`steward_contact_absent`:** true when the steward contact is unset, not ACTIVE, or no longer a current member of the owner organization.
- **Vocabulary:** codes match `^[A-Z0-9_]{2,64}$`, schemes `SUBJECT | METHOD | MATERIAL`.
  - The seed rows ship inside migration `catalog_0002` with `iri = NULL`. IRI mapping is a curation task (createVocabularyTerm / later admin UI); implementers must not invent IRIs.
  - Limits: subject ≤ 5, method ≤ 10, material ≤ 20 codes.
- **Snapshot (D-029):** `metadata_snapshot` gains the research fields and a `people` block. Two fields fall back so `09 §3.1` stays satisfiable without the retired inputs:
  - `contact_email` = `datasets.contact_email` or the steward contact's account email;
  - `domain` = `datasets.domain` or the first subject code.
  - Dates are ISO strings in the snapshot.
- **JSON-LD:** `GET /datasets/{dataset_id}/metadata.jsonld`, `Content-Type: application/ld+json`.
  - Contract: `content` declares both `application/ld+json` and `application/json` (same `$ref`) so the shared contract harness keeps working.
  - `@id` IRIs use `NAIS_PUBLIC_BASE_URL` + `/id/dataset/{id}`, `/id/person/{user_id}`, `/id/organization/{org_id}`, `/vocabulary/{scheme}/{code}`.

**Data Explorer**
- Tabular files are `.csv` (`,`), `.tsv` (tab) and `.parquet`, except files whose basename starts with `_` (09 §1.3).
- Profile sample limits, configurable:
  - `CATALOG_PREVIEW_MAX_ROWS=10000`, `CATALOG_PREVIEW_MAX_BYTES=67108864` (64 MiB), `CATALOG_PREVIEW_TIMEOUT_SECONDS=30` per file;
  - ≤ 200 columns (extra columns dropped, `columns_truncated=true`);
  - one physical CSV line ≤ 1 MiB (else `FAILED` with `failure_code=UNPARSEABLE`).
- Preview payload: first 100 rows, each cell truncated to 200 characters, the whole `preview` JSON ≤ 256 KiB (rows dropped from the end until it fits, `rows_truncated=true`).
- Visibility (spec §7 "열람 범위 규칙"):
  - `getFileProfile` → every user who can see the **version** (`access.can_see_version`). It holds column name, type, unit, description, concept IRI, missing ratio and distinct count. No raw values: `distinct_count` is a number, no examples.
  - `getFilePreview` → that, **and** download permission:
    - PLATFORM_ADMIN, or
    - a current member of the owner organization, or
    - dataset `access_level = PUBLIC`, or
    - `PreviewGrantLookup.has_active_grant(user_id, dataset_id)` is true. The default implementation `NoGrants` always says false; M04 provides the real one in Wave 2.
  - Otherwise `403 FORBIDDEN` with `details.reason = "DOWNLOAD_PERMISSION_REQUIRED"`. Invisible → 404.
- Statuses: `PENDING | READY | FAILED | UNSUPPORTED`. Non-tabular files get no row; the API answers `UNSUPPORTED` for them. Leasing:
  - `next_attempt_at` = now + 10 min when dispatched;
  - `attempts` ≤ 3, then `FAILED` (`failure_code=GENERATION_FAILED`);
  - `FileTimeout` → `FAILED` (`TIMEOUT`).

**Search and runtime**

## Review Focus

1. **A transferred user's old memberships must not duplicate rows.** After a transfer, `/me`, `listUsers`, `get_public_profiles`, `has_org_role` and the resolver each return exactly one row, from the current organization. Before this change every join assumed one membership per user. Pinned in Task 2 (`test_history_rows_never_duplicate_reads`).
2. **A steward edits a dataset after the PI moved to another institute.** Saving other fields must keep the stored `principal_investigator_org_id`; the PI is history. The steward contact *is* re-validated only when it changes. Pinned in Task 6 (`test_update_keeps_historic_pi_affiliation_after_transfer`).
3. **Raw values reaching a user without download permission.** An `a.researcher` looking at Institute B's CONTROLLED dataset must get the column profile — names, types, missing ratio — but `403` on the preview. The profile must not hide values in fields like "example" or "top value". A CSV cell holding `<script>` or 10 kB of text comes back truncated to 200 chars as plain JSON data. Pinned in Task 11 (`test_preview_requires_download_permission`, `test_profile_contains_no_raw_values`, `test_cells_are_truncated`).
4. **A date-only period filter with an open-ended dataset.** `temporal_from=2026-01-01` must find a dataset `2025-07-01 … (no end)` and must not find one `2024-01-01 … 2025-12-31`; `temporal_from > temporal_to` is 422, not a 500 from OpenSearch. Pinned in Task 9 (`test_temporal_overlap_includes_open_ended`, `test_inverted_temporal_range_is_422`).
5. **The steward contact's email when the toggle is off.** Neither `getDataset`, the contributors listing, the JSON-LD nor search hits may contain any person's email. Pinned in Task 6 (`test_email_only_when_contact_email_public`) and Task 8 (`test_jsonld_never_leaks_private_email`).

## Decisions taken while planning (spec gaps resolved)

- **The membership uniqueness key is `ended_at IS NULL`, not `status = 'ACTIVE'`** (spec §3.0b said ACTIVE). `updateOrganizationMember` can set a *current* membership to DISABLED; that user still belongs to the org, so DISABLED-but-current must stay unique too.
- **Keycloak is updated by a new `KeycloakAdminPort`** (M01 had none). The implementation uses the master-realm `admin-cli` password grant with `KEYCLOAK_ADMIN_USER`/`KEYCLOAK_ADMIN_PASSWORD` (dev, D-037). The new env key `KEYCLOAK_ADMIN_URL` defaults to `http://localhost:21051/auth` in code; `.env.example` sets `http://keycloak:8080/auth` for containers.
- **Tokens issued before a transfer** carry the old `org_code`. The resolver already answers `403 ORGANIZATION_UNKNOWN` until the user signs in again; this is documented in the identity README, not changed.
- **The seed never moves a transferred seed user back.** The membership upsert only updates a current membership in the *same* org.
- **`listVocabulary` returns all active terms of a scheme without pagination** (≤ a few hundred terms). `createVocabularyTerm` (PLATFORM_ADMIN) is included because the spec says "seed + 관리자 추가". Editing and deactivating terms are deferred.
- **Collecting organization:** the facet and filter use only `collecting_organization_id` (council institutes). A free-text `collecting_organization_name` is searchable through `q`.
- **The `domain` and `contact_email` inputs are kept in the API** for compatibility and read-only display. The web stops offering them (web plan). The snapshot fallbacks above keep readiness `metadata.completeness` passing for new datasets, so the spec's "completeness rules unchanged" (§9) still holds.
- **Contributors may be any ACTIVE user of any council organization** (spec §3.2). They are replaced as a whole by `PUT /datasets/{id}/contributors` (≤ 50 entries).
- **"JSON-LD passes the schema.org validator" (spec §8)** cannot run offline in CI. Task 8 instead pins the structure (`@context`, `@type`, `@id`, Person/Organization/DefinedTerm shapes). Task 12 includes a manual validator check that the controller does once.
- **Data Explorer reuse of M05 parsing:**
  - **Moved:** the capped raw reader, the bounded line iterator and `RangeReader`/`open_parquet_range` (M05's hostile-file hardening) move to `apps/api/platform/bounded_io.py`. `readiness/engine/parsing.py` re-imports them under their old names, so M05 code and tests are untouched.
  - **Not shared:** profiling itself (types, histograms, top values) is catalog code. M05's `profile_csv` checks validity against a declared schema, which is a different job, and catalog must not import readiness internals (D-038).
- **Preview generation is DB-leased, not fired from the publish request.** Seeds, retries and worker restarts all follow the same path; a lost actor message is re-dispatched after the 10-minute lease.
- **PUBLIC datasets allow previews for every viewer.** M04 treats PUBLIC as "approval not required" (Wave 1 web `ACCESS_NOT_REQUIRED`), so the rule "download permission" includes it.
- **The AI-ready 0–10 score is computed in the web** from `getReadiness` checks (web plan). No backend field is needed.
- **`subtitle` is plain text (≤ 160 chars)** and appears in:
  - create/update (nullable on update);
  - `Dataset`, `DatasetSearchHit`, the snapshot, and JSON-LD `alternativeHeadline`.
  
  The markdown rendering of `description` is web-only; the API stores and returns the raw markdown text as before.
- **Existing Wave 1 seed datasets get their research metadata through an idempotent backfill** in `catalog.seed()`: rows where `principal_investigator_id IS NULL` are filled. Their published versions keep their old (immutable) snapshots.

```python
"""Keycloak admin REST seam for transferUserOrganization (org_code user attribute, D-019 token claim)."""

from typing import Any, Protocol
from uuid import UUID

import httpx


class KeycloakAdminUnavailable(RuntimeError):  # noqa: N818
    pass


class KeycloakAdminPort(Protocol):
    def set_org_code(self, user_id: UUID, org_code: str) -> None: ...


class HttpKeycloakAdmin:
    """Master-realm admin-cli password grant (dev credentials, D-037), then GET + PUT the user representation."""

    def __init__(
        self,
        base_url: str,
        realm: str,
        admin_user: str,
        admin_password: str,
        *,
        timeout: float = 5.0,
        transport: httpx.BaseTransport | None = None,
    ) -> None:
        self._base = base_url.rstrip("/")
        self._realm = realm
        self._credentials = {"grant_type": "password", "client_id": "admin-cli", "username": admin_user,
                             "password": admin_password}
        self._timeout = timeout
        self._transport = transport

    def set_org_code(self, user_id: UUID, org_code: str) -> None:
        try:
            with httpx.Client(timeout=self._timeout, transport=self._transport) as client:
                token = self._ok(
                    client.post(f"{self._base}/realms/master/protocol/openid-connect/token", data=self._credentials)
                ).json()["access_token"]
                headers = {"Authorization": f"Bearer {token}"}
                url = f"{self._base}/admin/realms/{self._realm}/users/{user_id}"
                user: dict[str, Any] = self._ok(client.get(url, headers=headers)).json()
                attributes = dict(user.get("attributes") or {})
                attributes["org_code"] = [org_code]
                user["attributes"] = attributes
                self._ok(client.put(url, headers=headers, json=user))
        except (httpx.HTTPError, KeyError, ValueError) as exc:
            raise KeycloakAdminUnavailable(str(exc)) from exc

    @staticmethod
    def _ok(response: httpx.Response) -> httpx.Response:
        if response.status_code >= 300:
            raise KeycloakAdminUnavailable(f"keycloak admin {response.request.method} -> {response.status_code}")
        return response


class FakeKeycloakAdmin:
    def __init__(self) -> None:
        self.calls: list[tuple[UUID, str]] = []
        self.fail = False

    def set_org_code(self, user_id: UUID, org_code: str) -> None:
        if self.fail:
            raise KeycloakAdminUnavailable("fake failure")
        self.calls.append((user_id, org_code))
```

```python
def transfer_user(session: Session, actor: CurrentUser, user_id: UUID, body: TransferIn) -> MembershipOut:
    if not actor.is_platform_admin:
        raise ApiError(ErrorCode.FORBIDDEN, "Only a PLATFORM_ADMIN can move users between organizations.")
    if session.execute(select(users.c.user_id).where(users.c.user_id == user_id)).first() is None:
        raise ApiError(ErrorCode.NOT_FOUND)
    target = session.execute(
        select(organizations.c.organization_id, organizations.c.code).where(
            organizations.c.organization_id == body.organization_id
        )
    ).first()
    if target is None:
        raise ApiError(
            ErrorCode.VALIDATION_FAILED,
            "Unknown organization.",
            {"fields": [{"field": "organization_id", "reason": "UNKNOWN_ORGANIZATION"}]},
        )
    roles = _validated_roles(body.roles)
    current = session.execute(
        membership_select().where(memberships.c.user_id == user_id, CURRENT_MEMBERSHIP).with_for_update(of=memberships)
    ).first()
    if current is not None and current.organization_id == body.organization_id:
        _set_org_code(user_id, target.code)  # idempotent repair of the token claim
        return membership_out(current)

    now = clock.now()
    event_actor = EventActor.for_user(actor)
    if current is not None:
        session.execute(
            update(memberships)
            .where(memberships.c.user_id == user_id, CURRENT_MEMBERSHIP)
            .values(status="DISABLED", roles=[], ended_at=now, updated_at=now, updated_by=actor.user_id)
        )
        outbox.write(
            session,
            EventType.IDENTITY_MEMBERSHIP_CHANGED_V1,
            {
                "user_id": str(user_id),
                "organization_id": str(current.organization_id),
                "previous_roles": sorted(current.roles),
                "roles": [],
                "previous_status": current.status,
                "status": "DISABLED",
            },
            event_actor,
        )
    session.execute(
        insert(memberships).values(
            membership_id=new_id(),
            user_id=user_id,
            organization_id=body.organization_id,
            roles=roles,
            status="ACTIVE",
            started_at=now,
            created_at=now,
            updated_at=now,
            updated_by=actor.user_id,
        )
    )
    outbox.write(
        session,
        EventType.IDENTITY_MEMBERSHIP_CHANGED_V1,
        {
            "user_id": str(user_id),
            "organization_id": str(body.organization_id),
            "previous_roles": [],
            "roles": roles,
            "previous_status": "DISABLED",
            "status": "ACTIVE",
        },
        event_actor,
    )
    session.flush()
    _set_org_code(user_id, target.code)  # last: a failure raises and the request transaction rolls back
    row = session.execute(membership_select().where(memberships.c.user_id == user_id, CURRENT_MEMBERSHIP)).one()
    return membership_out(row)
```

```python
"""Controlled vocabulary (spec §3.1): list active terms, PLATFORM_ADMIN adds terms."""

from typing import Any

from sqlalchemy import insert, select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from api.modules.catalog.schemas import VocabularyTermIn
from api.modules.catalog.tables import vocabulary_terms
from api.platform.auth import CurrentUser
from api.platform.errors import ApiError
from api.platform.generated.error_codes import ErrorCode

FIELDS = ("scheme", "code", "label_ko", "label_en", "iri", "parent_code")


def active_codes(session: Session, scheme: str) -> set[str]:
    return set(
        session.execute(
            select(vocabulary_terms.c.code).where(vocabulary_terms.c.scheme == scheme, vocabulary_terms.c.active)
        ).scalars()
    )


def labels(session: Session, scheme: str, codes: list[str]) -> dict[str, dict[str, Any]]:
    if not codes:
        return {}
    found = session.execute(
        select(*(vocabulary_terms.c[f] for f in FIELDS)).where(
            vocabulary_terms.c.scheme == scheme, vocabulary_terms.c.code.in_(codes)
        )
    ).mappings()
    return {row["code"]: dict(row) for row in found}


def list_terms(session: Session, scheme: str) -> dict[str, Any]:
    found = session.execute(
        select(*(vocabulary_terms.c[f] for f in FIELDS))
        .where(vocabulary_terms.c.scheme == scheme, vocabulary_terms.c.active)
        .order_by(vocabulary_terms.c.parent_code.nulls_first(), vocabulary_terms.c.code)
    ).mappings()
    return {"items": [dict(row) for row in found]}


def create_term(session: Session, user: CurrentUser, scheme: str, body: VocabularyTermIn) -> dict[str, Any]:
    if not user.is_platform_admin:
        raise ApiError(ErrorCode.FORBIDDEN, "Only a PLATFORM_ADMIN can add vocabulary terms.")
    if body.parent_code is not None and body.parent_code not in active_codes(session, scheme):
        raise ApiError(
            ErrorCode.VALIDATION_FAILED,
            "Unknown parent term.",
            {"fields": [{"field": "parent_code", "reason": "VOCABULARY_TERM_UNKNOWN"}]},
        )
    values = {"scheme": scheme, **body.model_dump()}
    try:
        with session.begin_nested():
            session.execute(insert(vocabulary_terms).values(**values))
    except IntegrityError as exc:
        raise ApiError(ErrorCode.CONFLICT, "This code already exists in the scheme.") from exc
    return {field: values.get(field) for field in FIELDS}
```

```python
"""Research metadata rules (Wave 1.5 spec §3.0b, §3.2): eligibility of persons, vocabulary codes, period,
collecting organization, and the people block with at-the-time vs current affiliation."""

from collections.abc import Mapping
from typing import Any
from uuid import UUID

from sqlalchemy import select
from sqlalchemy.orm import Session

from api.modules.catalog.deps import CatalogDeps
from api.modules.catalog.interfaces import PersonSummary
from api.modules.catalog.service.vocabulary import active_codes
from api.modules.catalog.tables import dataset_contributors
from api.platform.errors import ApiError
from api.platform.generated.error_codes import ErrorCode

RESEARCH_FIELDS: tuple[str, ...] = (
    "subtitle", "principal_investigator_id", "data_steward_contact_id", "contact_email_public", "project_title",
    "project_code", "funding_agency", "subject_codes", "method_codes", "material_codes", "method_detail",
    "temporal_start", "temporal_end", "collecting_organization_id", "collecting_organization_name",
    "update_frequency", "related_publications",
)
SCHEMES = {"subject_codes": "SUBJECT", "method_codes": "METHOD", "material_codes": "MATERIAL"}
PEOPLE = {"principal_investigator_id": "principal_investigator_org_id",
          "data_steward_contact_id": "data_steward_contact_org_id"}


def _eligible_member(person: PersonSummary | None, owner: UUID) -> bool:
    return person is not None and person.status == "ACTIVE" and person.organization_id == owner


def validate_research(
    session: Session,
    deps: CatalogDeps,
    owner: UUID,
    values: dict[str, Any],
    *,
    current: Mapping[str, Any] | None = None,
) -> dict[str, Any]:
    """Return DB-ready values (adds *_org_id for newly assigned persons). Raises one 422 listing every problem."""
    problems: list[dict[str, str]] = []
    out = dict(values)
    assigned = [field for field in PEOPLE if values.get(field) is not None
                and (current is None or values[field] != current[field])]
    people = deps.organizations.get_people([values[f] for f in assigned])
    for field in assigned:
        person = people.get(values[field])
        if not _eligible_member(person, owner):
            problems.append({"field": field, "reason": "PERSON_NOT_ELIGIBLE"})
        else:
            assert person is not None
            out[PEOPLE[field]] = person.organization_id  # at-the-time affiliation
    for field, scheme in SCHEMES.items():
        codes = values.get(field)
        if codes and set(codes) - active_codes(session, scheme):
            problems.append({"field": field, "reason": "VOCABULARY_TERM_UNKNOWN"})
    start = values.get("temporal_start", current["temporal_start"] if current else None)
    end = values.get("temporal_end", current["temporal_end"] if current else None)
    if start is not None and end is not None and end < start:
        problems.append({"field": "temporal_end", "reason": "TEMPORAL_RANGE"})
    org_id = values.get("collecting_organization_id", current["collecting_organization_id"] if current else None)
    org_name = values.get("collecting_organization_name", current["collecting_organization_name"] if current else None)
    if org_id is not None and org_name is not None:
        problems.append({"field": "collecting_organization_name", "reason": "MUTUALLY_EXCLUSIVE"})
    if values.get("collecting_organization_id") is not None and deps.organizations.get_organization_summary(
        values["collecting_organization_id"]
    ) is None:
        problems.append({"field": "collecting_organization_id", "reason": "UNKNOWN_ORGANIZATION"})
    if problems:
        raise ApiError(ErrorCode.VALIDATION_FAILED, "Research metadata is invalid.", {"fields": problems})
    if "related_publications" in out and out["related_publications"] is not None:
        out["related_publications"] = [
            {k: v for k, v in p.items() if v is not None} for p in out["related_publications"]
        ]
    return out


def _org_ref(deps: CatalogDeps, org_id: UUID | None, cache: dict[UUID, str]) -> dict[str, Any] | None:
    if org_id is None:
        return None
    if org_id not in cache:
        summary = deps.organizations.get_organization_summary(org_id)
        cache[org_id] = summary.name if summary else str(org_id)
    return {"organization_id": org_id, "name": cache[org_id]}


def _person(
    deps: CatalogDeps, user_id: UUID, affiliation: UUID, found: dict[UUID, PersonSummary], cache: dict[UUID, str]
) -> dict[str, Any]:
    person = found.get(user_id)
    body: dict[str, Any] = {
        "user_id": user_id,
        "display_name": person.display_name if person else str(user_id),
        "national_researcher_number": person.national_researcher_number if person else None,
        "status": person.status if person else "DISABLED",
        "affiliation": _org_ref(deps, affiliation, cache),
        "current_organization": _org_ref(deps, person.organization_id, cache) if person else None,
    }
    return body


def contributor_rows(session: Session, dataset_id: UUID) -> list[Mapping[str, Any]]:
    return list(
        session.execute(
            select(dataset_contributors)
            .where(dataset_contributors.c.dataset_id == dataset_id)
            .order_by(dataset_contributors.c.position)
        ).mappings()
    )


def people_block(session: Session, deps: CatalogDeps, ds: Mapping[str, Any]) -> dict[str, Any]:
    contributors = contributor_rows(session, ds["dataset_id"])
    ids = [i for i in (ds["principal_investigator_id"], ds["data_steward_contact_id"]) if i is not None]
    ids += [c["user_id"] for c in contributors]
    found = deps.organizations.get_people(ids)
    cache: dict[UUID, str] = {}
    pi = (
        _person(deps, ds["principal_investigator_id"], ds["principal_investigator_org_id"], found, cache)
        if ds["principal_investigator_id"] else None
    )
    steward = (
        _person(deps, ds["data_steward_contact_id"], ds["data_steward_contact_org_id"], found, cache)
        if ds["data_steward_contact_id"] else None
    )
    steward_person = found.get(ds["data_steward_contact_id"]) if ds["data_steward_contact_id"] else None
    absent = not _eligible_member(steward_person, ds["owner_organization_id"])
    if steward is not None and ds["contact_email_public"] and not absent:
        email = deps.organizations.get_email(ds["data_steward_contact_id"])
        if email:
            steward["email"] = email
    return {
        "principal_investigator": pi,
        "steward_contact": steward,
        "contributors": [
            {**_person(deps, c["user_id"], c["affiliation_organization_id"], found, cache), "role": c["role"]}
            for c in contributors
        ],
        "steward_contact_absent": absent,
    }
```

```python
def put_contributors(
    session: Session, deps: CatalogDeps, user: CurrentUser, dataset_id: UUID, body: ContributorsPutIn
) -> dict[str, Any]:
    ds = visible_dataset(session, user, dataset_id, for_update=True)
    require_steward(user, ds)
    wanted = [(c.user_id, c.role) for c in body.contributors]
    problems: list[dict[str, str]] = []
    if len(set(wanted)) != len(wanted):
        problems.append({"field": "contributors", "reason": "DUPLICATE"})
    existing = {(r["user_id"], r["role"]): r for r in contributor_rows(session, dataset_id)}
    new_ids = [uid for uid, role in wanted if (uid, role) not in existing]
    people = deps.organizations.get_people(new_ids)
    for index, (uid, role) in enumerate(wanted):
        if (uid, role) not in existing and (people.get(uid) is None or people[uid].status != "ACTIVE"):
            problems.append({"field": f"contributors[{index}].user_id", "reason": "PERSON_NOT_ELIGIBLE"})
    if problems:
        raise ApiError(ErrorCode.VALIDATION_FAILED, "Contributors are invalid.", {"fields": problems})
    if wanted == [key for key in existing]:  # same pairs in the same order
        return {"items": people_block(session, deps, ds)["contributors"]}
    session.execute(delete(dataset_contributors).where(dataset_contributors.c.dataset_id == dataset_id))
    for position, (uid, role) in enumerate(wanted):
        affiliation = existing[(uid, role)]["affiliation_organization_id"] if (uid, role) in existing else people[uid].organization_id
        session.execute(
            insert(dataset_contributors).values(
                dataset_id=dataset_id, user_id=uid, role=role, affiliation_organization_id=affiliation, position=position
            )
        )
    session.execute(update(datasets).where(datasets.c.dataset_id == dataset_id).values(updated_at=clock.now()))
    outbox.write(
        session,
        "catalog.dataset.metadata_changed.v1",
        {"dataset_id": str(dataset_id), "owner_organization_id": str(ds["owner_organization_id"]),
         "changed_fields": ["contributors"]},
        EventActor.for_user(user),
    )
    enqueue_index(session, dataset_id)
    return {"items": people_block(session, deps, ds)["contributors"]}
```

```python
    "dct": "http://purl.org/dc/terms/",
    "prov": "http://www.w3.org/ns/prov#",
}


def _person(base: str, p: Mapping[str, Any]) -> dict[str, Any]:
    node: dict[str, Any] = {"@type": "Person", "@id": f"{base}/id/person/{p['user_id']}", "name": p["display_name"]}
    if p.get("national_researcher_number"):
        node["identifier"] = {"@type": "PropertyValue", "propertyID": "NTIS", "value": p["national_researcher_number"]}
    if p.get("affiliation"):
        node["affiliation"] = _org(base, p["affiliation"])
    if p.get("email"):
        node["email"] = p["email"]
    return node


def _org(base: str, ref: Mapping[str, Any]) -> dict[str, Any]:
    node: dict[str, Any] = {"@type": "Organization", "name": ref["name"]}
    if ref.get("organization_id"):
        node = {"@type": "Organization", "@id": f"{base}/id/organization/{ref['organization_id']}", "name": ref["name"]}
    return node


def _terms(session: Session, base: str, scheme: str, codes: list[str]) -> list[dict[str, Any]]:
    found = labels(session, scheme, codes)
    out = []
    for code in codes:
        term: dict[str, Any] = {"@type": "DefinedTerm", "termCode": code, "name": found.get(code, {}).get("label_ko", code),
                                "inDefinedTermSet": f"{base}/vocabulary/{scheme}"}
        iri = found.get(code, {}).get("iri")
        if iri:
            term["sameAs"] = iri
        out.append(term)
    return out
```

```python
"""_schema.json (09 §1.2 subset) → per-file column hints for the Data Explorer. Tolerant: anything malformed is
ignored (readiness reports schema problems; the explorer only decorates)."""

import json
from typing import Any

from api.modules.catalog.previews.profile import FieldHint

TYPES = {"string", "integer", "number", "boolean", "date", "datetime"}


def _text(value: Any) -> str | None:
    return value if isinstance(value, str) and value.strip() else None


def parse_schema_hints(raw: bytes) -> dict[str, dict[str, FieldHint]]:
    try:
        doc = json.loads(raw.decode("utf-8-sig"))
    except (UnicodeDecodeError, json.JSONDecodeError):
        return {}
    out: dict[str, dict[str, FieldHint]] = {}
    for resource in doc.get("resources", []) if isinstance(doc, dict) else []:
        if not isinstance(resource, dict) or not isinstance(resource.get("path"), str):
            continue
        fields = (resource.get("schema") or {}).get("fields") or []
        hints: dict[str, FieldHint] = {}
        for f in fields if isinstance(fields, list) else []:
            if isinstance(f, dict) and isinstance(f.get("name"), str):
                concept = _text(f.get("x-nais-concept"))
                hints[f["name"]] = FieldHint(
                    f.get("type") if f.get("type") in TYPES else None,
                    _text(f.get("unit")),
                    _text(f.get("description")),
                    concept if concept and concept.startswith(("http://", "https://")) else None,
                )
        out[resource["path"]] = hints
    return out
```

```python
_BOOLEAN = frozenset({"true", "false", "True", "False", "TRUE", "FALSE"})
MAX_TYPED_LEN = 64  # longer values are never numbers/dates: skip the regex (ReDoS-safe, like 09 §1.4)


class PreviewTimeout(Exception):
    pass


class Unparseable(Exception):
    pass


@dataclass(frozen=True)
class PreviewLimits:
    max_rows: int = 10_000
    max_bytes: int = 64 << 20
    max_columns: int = 200
    preview_rows: int = 100
    cell_chars: int = 200
    preview_bytes: int = 256 << 10
    distinct_cap: int = 1_000
    histogram_bins: int = 10
    top_values: int = 10


@dataclass(frozen=True)
class FieldHint:
    type: str | None = None
    unit: str | None = None
    description: str | None = None
    concept_iri: str | None = None


@dataclass
class ProfileResult:
    format: str
    rows_sampled: int
    truncated: bool
    columns_truncated: bool
    column_profile: list[dict[str, Any]]
    preview: dict[str, Any]


@dataclass
class _Column:
    name: str
    hint: FieldHint
    seen: int = 0
    missing: int = 0
    distinct: set[int] = field(default_factory=set)
    distinct_capped: bool = False
    type_hits: Counter[str] = field(default_factory=Counter)
    numbers: list[float] = field(default_factory=list)
    n_numeric: int = 0
    total: float = 0.0
    low: float = math.inf
    high: float = -math.inf
    counts: Counter[str] = field(default_factory=Counter)


def table_format(path: str) -> str | None:
    name = path.rsplit("/", 1)[-1]
    if name.startswith("_"):
        return None
    lower = name.lower()
    for ext, fmt in ((".csv", "csv"), (".tsv", "tsv"), (".parquet", "parquet")):
        if lower.endswith(ext):
            return fmt
    return None


def make_deadline(seconds: float, clock: Callable[[], float] = time.monotonic) -> Deadline:
    end = clock() + seconds

    def check() -> None:
        if clock() > end:
            raise PreviewTimeout

    return check


def _types_of(value: str) -> list[str]:
    if value in _BOOLEAN:
        return ["boolean"]
    if len(value) > MAX_TYPED_LEN:
        return []
    return [t for t in ("integer", "number", "date", "datetime") if _PATTERNS[t].fullmatch(value)]


def _observe(col: _Column, value: str | None, limits: PreviewLimits, rng: random.Random) -> None:
    col.seen += 1
    if value is None or value in MISSING:
        col.missing += 1
        return
    if not col.distinct_capped:
        col.distinct.add(hash(value))
        if len(col.distinct) > limits.distinct_cap:
            col.distinct_capped = True
    if len(col.counts) < limits.distinct_cap or value in col.counts:
        col.counts[value[: limits.cell_chars]] += 1
    for t in _types_of(value):
        col.type_hits[t] += 1
    if "number" in _types_of(value):
        x = float(value)
        if math.isfinite(x):
            col.n_numeric += 1
            col.total += x
            col.low, col.high = min(col.low, x), max(col.high, x)
            if len(col.numbers) < RESERVOIR:
                col.numbers.append(x)
            else:
                j = rng.randrange(col.n_numeric)
                if j < RESERVOIR:
                    col.numbers[j] = x


def _column_type(col: _Column) -> str:
    if col.hint.type:
        return col.hint.type
    present = col.seen - col.missing
    if present == 0:
        return "string"
    for t in TYPE_ORDER:
        if col.type_hits[t] == present:
            return t
    return "string"


def _histogram(col: _Column, bins: int) -> list[dict[str, Any]]:
    if not col.numbers or col.low == col.high:
        return [{"lower": col.low, "upper": col.high, "count": col.n_numeric}] if col.numbers else []
    width = (col.high - col.low) / bins
    counts = [0] * bins
    for x in col.numbers:
        counts[min(int((x - col.low) / width), bins - 1)] += 1
    scale = col.n_numeric / len(col.numbers)
    out = [
        {"lower": round(col.low + i * width, 6), "upper": round(col.low + (i + 1) * width, 6), "count": round(c * scale)}
        for i, c in enumerate(counts)
    ]
    out[-1]["count"] += col.n_numeric - sum(b["count"] for b in out)  # keep the total exact after scaling
    return out


def _distribution(col: _Column, ctype: str, limits: PreviewLimits) -> dict[str, Any]:
    if ctype in ("integer", "number") and col.n_numeric:
        return {"name": col.name, "kind": "numeric", "min": col.low, "max": col.high,
                "mean": round(col.total / col.n_numeric, 6), "histogram": _histogram(col, limits.histogram_bins)}
    if ctype == "boolean" or (not col.distinct_capped and len(col.distinct) <= CATEGORICAL_MAX_DISTINCT):
        return {"name": col.name, "kind": "categorical",
                "top_values": [{"value": v, "count": n} for v, n in col.counts.most_common(limits.top_values)]}
    return {"name": col.name, "kind": "other"}


def _cell(value: Any, limits: PreviewLimits) -> str | None:
    if value is None:
        return None
    text = value if isinstance(value, str) else str(value)
    return None if text in MISSING else text[: limits.cell_chars]


def _finish(fmt: str, cols: list[_Column], rows: list[list[str | None]], sampled: int, truncated: bool,
            columns_truncated: bool, limits: PreviewLimits) -> ProfileResult:
    profile, dists = [], []
    for col in cols:
        ctype = _column_type(col)
        profile.append({
            "name": col.name, "type": ctype, "unit": col.hint.unit, "description": col.hint.description,
            "concept_iri": col.hint.concept_iri,
            "missing_ratio": round(col.missing / col.seen, 6) if col.seen else 0.0,
            "distinct_count": len(col.distinct), "distinct_capped": col.distinct_capped,
        })
        dists.append(_distribution(col, ctype, limits))
    preview: dict[str, Any] = {"header": [c.name for c in cols], "rows": rows, "rows_truncated": False, "columns": dists}
    while preview["rows"] and len(json.dumps(preview, ensure_ascii=False).encode()) > limits.preview_bytes:
        preview["rows"] = preview["rows"][: max(0, len(preview["rows"]) * 3 // 4)]
        preview["rows_truncated"] = True
    return ProfileResult(fmt, sampled, truncated, columns_truncated, profile, preview)


def _profile_delimited(stream: BinaryIO, fmt: str, hints: dict[str, FieldHint], limits: PreviewLimits,
                       deadline: Deadline) -> ProfileResult:
    text = io.TextIOWrapper(io.BufferedReader(CappedRaw(stream, deadline)), encoding="utf-8-sig", newline="")
    lines = BoundedLines(text, min(limits.max_bytes, LINE_CAP))
    reader = csv.reader(lines, delimiter="\t" if fmt == "tsv" else ",")
    rng = random.Random(0)
    try:
        try:
            header = next(reader)
        except (StopIteration, csv.Error) as exc:
            raise Unparseable from exc
        if lines.overflow or not header:
            raise Unparseable
        columns_truncated = len(header) > limits.max_columns
        names = header[: limits.max_columns]
        cols = [_Column(n, hints.get(n, FieldHint())) for n in names]
        lines.bytes = 0
        rows: list[list[str | None]] = []
        sampled, truncated = 0, False
        while True:
            deadline()
            try:
                row = next(reader)
            except StopIteration:
                break
            except csv.Error:
                continue
            if lines.overflow:
                raise Unparseable
            if not row:
                continue
            if sampled >= limits.max_rows or lines.bytes > limits.max_bytes:
                truncated = True
                break
            if len(row) != len(header):
                continue  # malformed row: readiness reports it; the explorer skips it
            sampled += 1
            for col, value in zip(cols, row, strict=False):
                _observe(col, value, limits, rng)
            if len(rows) < limits.preview_rows:
                rows.append([_cell(v, limits) for v in row[: limits.max_columns]])
    except UnicodeDecodeError as exc:
        raise Unparseable from exc
    finally:
        text.detach()
    return _finish(fmt, cols, rows, sampled, truncated, columns_truncated, limits)


_ARROW_TYPES = (("is_boolean", "boolean"), ("is_integer", "integer"), ("is_floating", "number"),
                ("is_decimal", "number"), ("is_date", "date"), ("is_timestamp", "datetime"))


def _profile_parquet(source: BinaryIO, hints: dict[str, FieldHint], limits: PreviewLimits,
                     deadline: Deadline) -> ProfileResult:
    import pyarrow as pa
    import pyarrow.parquet as pq

    try:
        pf = pq.ParquetFile(source)
    except (pa.ArrowInvalid, pa.ArrowNotImplementedError, pa.ArrowIOError) as exc:
        raise Unparseable from exc
    names = list(pf.schema_arrow.names)
    columns_truncated = len(names) > limits.max_columns
    names = names[: limits.max_columns]
    cols = []
    for n in names:
        arrow_type = pf.schema_arrow.field(n).type
        declared = next((t for check, t in _ARROW_TYPES if getattr(pa.types, check)(arrow_type)), "string")
        hint = hints.get(n, FieldHint())
        cols.append(_Column(n, FieldHint(hint.type or declared, hint.unit, hint.description, hint.concept_iri)))
    rng = random.Random(0)
    rows: list[list[str | None]] = []
    sampled, truncated = 0, False
    try:
        for batch in pf.iter_batches(batch_size=1024, columns=names):
            deadline()
            data = [batch.column(i).to_pylist() for i in range(batch.num_columns)]
            for r in range(batch.num_rows):
                if sampled >= limits.max_rows:
                    truncated = True
                    break
                sampled += 1
                values = [None if col[r] is None else str(col[r]) for col in data]
                for col, value in zip(cols, values, strict=True):
                    _observe(col, value, limits, rng)
                if len(rows) < limits.preview_rows:
                    rows.append([_cell(v, limits) for v in values])
            if truncated:
                break
    except (pa.ArrowInvalid, pa.ArrowNotImplementedError) as exc:
        raise Unparseable from exc
    return _finish("parquet", cols, rows, sampled, truncated, columns_truncated, limits)


def profile_table(
    open_range: Callable[[int, int], BinaryIO],
    size: int,
    *,
    path: str,
    hints: dict[str, FieldHint],
    limits: PreviewLimits,
    deadline: Deadline,
) -> ProfileResult:
    fmt = table_format(path)
    if fmt is None:
        raise ValueError(f"not a tabular file: {path}")
    if size == 0:
        raise Unparseable
    if fmt == "parquet":
        return _profile_parquet(open_parquet_range(open_range, size, deadline=deadline), hints, limits, deadline)
    stream = open_range(0, size - 1)
    try:
        return _profile_delimited(stream, fmt, hints, limits, deadline)
    finally:
        stream.close()
```

```python
"""Data Explorer generation: a scheduler job leases PENDING rows and sends catalog.generate_preview messages; the
actor profiles the object with bounded readers (spec §7, 09 §1.4 limits). A lost message is re-sent after the lease."""

import logging
from collections.abc import Callable
from datetime import timedelta
from uuid import UUID

import dramatiq
from sqlalchemy import select, update
from sqlalchemy.orm import Session

from api.modules.catalog.deps import CatalogDeps
from api.modules.catalog.previews.profile import (
    PreviewLimits,
    PreviewTimeout,
    Unparseable,
    make_deadline,
    profile_table,
)
from api.modules.catalog.previews.schema_hints import parse_schema_hints
from api.modules.catalog.public import ObjectMissing, StorageUnavailable
from api.modules.catalog.tables import dataset_files, dataset_versions, datasets, file_previews
from api.platform import clock

logger = logging.getLogger("nais.catalog.previews")
MAX_ATTEMPTS = 3
SCHEMA_MAX_BYTES = 1 << 20


def dispatch_previews(deps: CatalogDeps, *, limit: int = 20, send: Callable[[str], None] | None = None) -> int:
    sender = send or (lambda file_id: generate_preview_actor.send(file_id))
    now = clock.now()
    with deps.session_factory() as session, session.begin():
        due = session.execute(
            select(file_previews.c.file_id, file_previews.c.attempts)
            .where(file_previews.c.status == "PENDING", file_previews.c.next_attempt_at <= now)
            .order_by(file_previews.c.next_attempt_at)
            .limit(limit)
            .with_for_update(skip_locked=True)
        ).all()
        to_send: list[str] = []
        for row in due:
            if row.attempts >= MAX_ATTEMPTS:
                session.execute(
                    update(file_previews).where(file_previews.c.file_id == row.file_id)
                    .values(status="FAILED", failure_code="GENERATION_FAILED")
                )
                continue
            session.execute(
                update(file_previews).where(file_previews.c.file_id == row.file_id).values(
                    attempts=row.attempts + 1,
                    next_attempt_at=now + timedelta(seconds=deps.settings.catalog_preview_lease_seconds),
                )
            )
            to_send.append(str(row.file_id))
    for file_id in to_send:  # after commit
        sender(file_id)
    return len(to_send)


def _finish(session: Session, file_id: UUID, **values: object) -> None:
    session.execute(
        update(file_previews)
        .where(file_previews.c.file_id == file_id, file_previews.c.status == "PENDING")
        .values(**values)
    )


def generate_preview_job(file_id: UUID, *, deps: CatalogDeps) -> str:
    with deps.session_factory() as session:
        row = session.execute(
            select(dataset_files, datasets.c.owner_organization_id, file_previews.c.status.label("preview_status"))
            .join(file_previews, file_previews.c.file_id == dataset_files.c.file_id)
            .join(dataset_versions, dataset_versions.c.dataset_version_id == dataset_files.c.dataset_version_id)
            .join(datasets, datasets.c.dataset_id == dataset_versions.c.dataset_id)
            .where(dataset_files.c.file_id == file_id)
        ).mappings().first()
        schema = None
        if row is not None:
            schema = session.execute(
                select(dataset_files.c.storage_key, dataset_files.c.size_bytes).where(
                    dataset_files.c.dataset_version_id == row["dataset_version_id"],
                    dataset_files.c.path == "_schema.json",
                    dataset_files.c.status == "VERIFIED",
                )
            ).first()
    if row is None or row["preview_status"] != "PENDING":
        return "SKIPPED"
    org = deps.organizations.get_organization_summary(row["owner_organization_id"])
    if org is None:
        return "SKIPPED"
    store = deps.storage.for_org(org.code)
    settings = deps.settings
    try:
        hints = {}
        if schema is not None and schema.size_bytes <= SCHEMA_MAX_BYTES:
            hints = parse_schema_hints(store.read_range(schema.storage_key, 0, schema.size_bytes - 1)).get(row["path"], {})
        result = profile_table(
            lambda start, end: store.open_stream(row["storage_key"], (start, end)),
            int(row["size_bytes"]),
            path=row["path"],
            hints=hints,
            limits=PreviewLimits(max_rows=settings.catalog_preview_max_rows, max_bytes=settings.catalog_preview_max_bytes),
            deadline=make_deadline(settings.catalog_preview_timeout_seconds),
        )
    except (StorageUnavailable, ObjectMissing):
        logger.warning("preview source unavailable; lease will retry", extra={"file_id": str(file_id)})
        return "PENDING"
    except Unparseable:
        status, values = "FAILED", {"status": "FAILED", "failure_code": "UNPARSEABLE"}
    except PreviewTimeout:
        status, values = "FAILED", {"status": "FAILED", "failure_code": "TIMEOUT"}
    else:
        status = "READY"
        values = {
            "status": "READY",
            "column_profile": {
                "format": result.format, "rows_sampled": result.rows_sampled, "truncated": result.truncated,
                "columns_truncated": result.columns_truncated, "columns": result.column_profile,
            },
            "preview": result.preview,
            "generated_at": clock.now(),
        }
    with deps.session_factory() as session, session.begin():
        _finish(session, file_id, **values)
    return status


@dramatiq.actor(queue_name="catalog", actor_name="catalog.generate_preview", max_retries=0, time_limit=120_000)
def generate_preview_actor(file_id: str) -> None:
    from api.modules.catalog.jobs import _deps  # late: wiring happens at worker start

    generate_preview_job(UUID(file_id), deps=_deps())
```

```python
from typing import Any
from uuid import UUID

from sqlalchemy import select
from sqlalchemy.orm import Session

from api.modules.catalog.access import can_see_version, not_found
from api.modules.catalog.deps import CatalogDeps

from api.platform.auth import CurrentUser

from api.platform.generated.error_codes import ErrorCode


def _load(session: Session, user: CurrentUser, file_id: UUID) -> tuple[Any, Any, Any]:
    f = session.execute(select(dataset_files).where(dataset_files.c.file_id == file_id)).mappings().first()
    if f is None:
        raise not_found("File")
    version = must(load_version(session, f["dataset_version_id"]), "version")
    ds = must(load_dataset(session, version["dataset_id"]), "dataset")
    if not can_see_version(user, ds, version):
        raise not_found("File")
    row = session.execute(select(file_previews).where(file_previews.c.file_id == file_id)).mappings().first()
    return f, ds, row


def can_preview(user: CurrentUser, ds: Any, deps: CatalogDeps) -> bool:
    return (
        user.is_platform_admin
        or user.organization_id == ds["owner_organization_id"]
        or ds["access_level"] == "PUBLIC"
        or deps.grants.has_active_grant(user.user_id, ds["dataset_id"])
    )


def _status(f: Any, row: Any) -> str:
    if row is None or table_format(f["path"]) is None:
        return "UNSUPPORTED"
    return str(row["status"])


def get_profile(session: Session, user: CurrentUser, file_id: UUID) -> dict[str, Any]:
    f, _, row = _load(session, user, file_id)
    status = _status(f, row)
    body: dict[str, Any] = {"file_id": file_id, "path": f["path"], "status": status, "columns": []}
    if row is not None:
        body.update(failure_code=row["failure_code"], generated_at=row["generated_at"])
    if status == "READY":
        profile = row["column_profile"]
        body.update(format=profile["format"], rows_sampled=profile["rows_sampled"], truncated=profile["truncated"],
                    columns_truncated=profile["columns_truncated"], columns=profile["columns"])
    return body


def get_preview(session: Session, deps: CatalogDeps, user: CurrentUser, file_id: UUID) -> dict[str, Any]:
    f, ds, row = _load(session, user, file_id)
    if not can_preview(user, ds, deps):
        raise ApiError(
            ErrorCode.FORBIDDEN,
            "접근 승인 후 미리보기를 볼 수 있습니다.",
            {"reason": "DOWNLOAD_PERMISSION_REQUIRED"},
        )
    status = _status(f, row)
    body: dict[str, Any] = {"file_id": file_id, "status": status, "header": [], "rows": [], "rows_truncated": False,
                            "columns": []}
    if status == "READY":
        body.update(row["preview"])
    return body
```
