# M07 Notebooks (Kaggle Notebooks형) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Attach Kaggle-style Jupyter notebooks to datasets and projects. Notebooks run in a sandbox on this server and are saved as re-executed versions. Their output is shown in the portal and they can be forked.

**Architecture:**
- **Backend.** A new backend module `apps/api/modules/notebooks` (owner M07, DB schema `notebooks`) is the only authority for notebook metadata, visibility, session policy and versions.
- **Infra.** Three new containers sit around it:
  - `notebook-hub`: JupyterHub with DockerSpawner, Keycloak OIDC, a pre-spawn policy hook and the `nais-bridge` Hub service.
  - `notebook-runner`: data loader, plus re-execution of saved versions in one-off containers.
  - `docker-proxy`: a docker-socket-proxy allow-list, so neither of the others holds `docker.sock`.
- **User containers** run on an internal Docker network with no route to NAIS services. They get their data as hard-linked, read-only files from a content-addressed cache.
- **Portal.** The web portal lists notebooks and shows saved versions as sanitized HTML in a scriptless sandboxed iframe. The editor is JupyterLab under `/notebooks/`.

**Tech Stack:**
- Backend: Python 3.13, FastAPI, SQLAlchemy 2, Alembic, Dramatiq (existing), `nh3` (new, HTML sanitizer).
- Hub: JupyterHub 5.x, `dockerspawner` 13.x, `oauthenticator` 17.x, `jupyterhub-idle-culler`.
- Notebook image: `jupyter/docker-stacks` `scipy-notebook`. Runner: `nbclient`, `nbconvert`, `docker` SDK 7.x.
- Infra: `tecnativa/docker-socket-proxy`, devpi-server (stage 3), squid (stage 3).
- Web: Next.js 15, TanStack Query, MSW (existing).

**Spec:** `docs/superpowers/specs/2026-10-01-notebooks-design.md` (decisions N1–N7, §2–§11). Stage 4 (GPU) is the appendix only.

**Visibility and permission (exact)**
- Notebook visible to a user:
  - `PRIVATE`: owner, PLATFORM_ADMIN.
  - `PROJECT`: those, plus ACTIVE members of `project_id` (`ProjectQueryPort.is_active_member`).
  - `DATASET_PUBLIC`: those, plus any user for whom **every** attached dataset is visible (`CatalogQueryPort.is_visible`).
  - Otherwise `404 NOT_FOUND` (existence hidden).
- **Output rule:** a version's outputs (rendered HTML with outputs, result ipynb) are returned only if, for every attached dataset whose `access_level ∈ {CONTROLLED, SENSITIVE}`, `CatalogDataAccessPort.can_read_data(user, dataset_id)` is true. Otherwise the API returns the **code-only** render (outputs stripped) and `outputs_hidden: true`.
- **Data permission** `can_read_data` is the Data Explorer rule: PLATFORM_ADMIN, owner-organization member, `access_level = PUBLIC`, or an ACTIVE grant via `PreviewGrantLookup`. Until M04 that lookup is `NoGrants`.
- **Attaching a dataset** needs `can_read_data` on a PUBLISHED version; otherwise `403 FORBIDDEN` `details.reason = "DATA_PERMISSION_REQUIRED"`. On fork, attachments the forker cannot read are kept but flagged `mountable: false`.
- **Internet:** `internet_enabled = true` is rejected (`422 VALIDATION_FAILED`, field `internet_enabled`, reason `CONTROLLED_DATA_ATTACHED`) when any attached dataset is CONTROLLED/SENSITIVE. Attaching such a dataset forces `internet_enabled = false`.

**Sandbox (exact values)**
- **User container:**
  - user `1000:100`; `cap_drop=["ALL"]`; `security_opt=["no-new-privileges:true"]`; `read_only=True`; `privileged` never set;
  - `tmpfs={"/tmp": "size=1g", "/home/jovyan/.local": "size=2g"}`; pids limit `512`;
  - CPU `2` (`nano_cpus=2_000_000_000`), memory `4g`, `memswap_limit` = memory;
  - workspace volume `nais-nb-home-{user_id}` at `/home/jovyan/work`, 10 GiB soft quota checked by the runner sweeper;
  - network `nais_nb` only (internal: true).
- **Session limits:** `NOTEBOOK_MAX_SESSIONS=4`, idle cull `3600` s, max age `43200` s; run timeout `3600` s; runner concurrency 1.
- **docker-proxy allow-list:** `CONTAINERS=1 POST=1 NETWORKS=0 VOLUMES=1 IMAGES=1 EXEC=0 BUILD=0 COMMIT=0 SWARM=0 SERVICES=0 TASKS=0 SECRETS=0 CONFIGS=0 PLUGINS=0 SYSTEM=0 INFO=1 VERSION=1 PING=1 EVENTS=0 AUTH=0`.
  - The spawner kwargs builder refuses `privileged`, host network, host PID/IPC, device requests (except GPU profiles in stage 4), bind mounts other than the session data dir, and capabilities other than none.
- **Data mounts:** host directory `NOTEBOOK_DATA_CACHE_DIR` (default `/data/nais/nb-cache`):
  - blobs at `blobs/<sha256>` (mode 0444, owner root);
  - per-session trees at `sessions/<session_id>/<slug>/<version_label>/<path>`, hard links to blobs;
  - mounted read-only at `/data/input`;
  - cache cap `NOTEBOOK_DATA_CACHE_GIB=200`, LRU eviction of blobs not linked by a live session.
- **Internal endpoints** `/api/v1/internal/**` require header `X-NAIS-Service-Token: <NOTEBOOK_SERVICE_TOKEN>` (constant-time compare) and are denied by the gateway (`location /api/v1/internal/ { return 404; }`).
- **Render:**
  - HTML is sanitized by `nh3` with a fixed allow-list: no `script`, `iframe`, `object`, `embed`, `form`, `on*` attributes or `javascript:` URLs; `img src` limited to `data:image/(png|jpeg|gif|svg+xml)` — SVG data URIs are allowed only in `<img>`, never inline.
  - It is served with `Content-Security-Policy: sandbox; default-src 'none'; img-src data:; style-src 'unsafe-inline'; font-src data:`, `X-Content-Type-Options: nosniff` and `Cross-Origin-Resource-Policy: same-origin`.
  - The portal embeds it with `<iframe sandbox="">` (no `allow-scripts`, no `allow-same-origin`).

**Events (producer `notebooks`)**
- `notebooks.notebook.created.v1` `{notebook_id, owner_user_id, owner_organization_id, project_id|null, forked_from_version_id|null}`
- `notebooks.notebook.shared.v1` `{notebook_id, owner_organization_id, visibility, project_id|null}`
- `notebooks.dataset.attached.v1` `{notebook_id, owner_organization_id, dataset_id, dataset_version_id}`
- `notebooks.session.started.v1` `{session_id, notebook_id, user_id, organization_id, profile, image_tag, internet_enabled}`
- `notebooks.session.ended.v1` `{session_id, notebook_id, user_id, organization_id, end_reason}`
- `notebooks.version.saved.v1` `{notebook_id, version_id, seq, owner_organization_id, run_status, dataset_version_ids[]}`

Audit actions are `NOTEBOOK_CREATED`, `NOTEBOOK_SHARED`, `NOTEBOOK_DATA_ATTACHED`, `NOTEBOOK_SESSION_STARTED`, `NOTEBOOK_SESSION_ENDED` and `NOTEBOOK_VERSION_SAVED`, with ResourceType `NOTEBOOK`.

## Review Focus

1. **A user container trying to reach NAIS internals** (`postgres:5432`, `redis:6379`, `api:8000`, `keycloak:8080`, `storage-a:8333`, the docker proxy) must fail to connect; only `notebook-hub` and (stage 3) `pypi-mirror`/`nb-egress` resolve. Pinned by `scripts/notebook_smoke.py` checks `isolation.*` (Task 10) and the compose-network test in Task 7.
2. **Outputs of a CONTROLLED-data notebook shown to a project member without data permission:** they must see code only (`outputs_hidden: true`, no `<img>`/output text from cells), even after forking. Pinned in Task 4 `test_outputs_hidden_without_data_permission` and `test_fork_keeps_unmountable_attachment`.
3. **Notebook HTML carrying `<script>`, `onerror=`, `<iframe>`, `javascript:` links or an SVG with script:** the stored render has none of it, and the response carries the sandbox CSP. Pinned in Task 4 `test_render_is_sanitized_and_sandboxed`.
4. **Two browser tabs starting a fifth concurrent session, or the same user starting twice:** the fifth gets `409 CONFLICT SESSION_LIMIT`; the same user reuses their live session (one per user). Pinned in Task 5 `test_session_cap_and_reuse`.
5. **Spawner configuration drift (someone adds `privileged`, a host bind or a capability):** `build_container_kwargs` rejects it and the unit test fails. Pinned in Task 7 `test_kwargs_reject_dangerous_options`.

## Decisions taken while planning (spec gaps resolved)

- **Module folder `apps/api/modules/notebooks`, schema `notebooks`.** The spec names the module `notebooks`; `module_ownership.json` M07 gets the new paths (`compute` stays reserved for the GPU resource catalog). `DEFAULT_MODULE_ORDER` gains `"notebooks"` so `discover_modules` loads it.
- **No new port for the render origin.** Ports 21051–21058 are all taken. The render endpoint returns the CSP `sandbox` header, so the document gets an opaque origin even when opened directly. Together with `<iframe sandbox="">` and server-side sanitization this replaces the spec's "different origin".
- **Who talks to whom.** User containers cannot reach the API (sandbox).
  - Autosave and "버전 저장" from inside JupyterLab go to the **`nais-bridge` Hub service** (`/notebooks/services/nais-bridge/`, authenticated by the user's Hub token).
  - The bridge forwards to the NAIS API with the user's **own Keycloak access token** from the authenticator's `auth_state`, so the API applies its normal user checks.
  - The Keycloak client `nais-jupyterhub` gets an audience mapper for `nais-api`.
- **Policy is fetched with the user's token**, not a service secret: `GET /notebooks/{id}/session-policy`. Only the runner uses the service token, on `/api/v1/internal/notebook-runs/*` and `/api/v1/internal/notebook-files/{file_id}`.
- **The data loader lives in `notebook-runner`.** It is the only component with the cache directory read-write. The Hub's pre-spawn hook calls `POST http://notebook-runner:8090/sessions/{session_id}/prepare` (control network, service token) and waits up to 300 s.
- **`CatalogReadPort.open_stream`** was documented as "readiness only" (D-018). It now also serves the runner, via the internal file endpoint, after the notebooks module checks `can_read_data` for the session owner. This is recorded as **D-042** in the decision log (Task 15).
- **Drafts are stored in the user's workspace volume first**, and in the API (`PUT /notebooks/{id}/draft`) through the bridge's post-save hook, at most once per 30 s per notebook. The API keeps only the latest draft.
- **Real editing needs real Keycloak login.** The portal runs in mock mode in Wave 1.5: the "열기" button shows "실서버 모드에서 사용 가능" there. The Hub itself works through direct Keycloak login (nais/nais dev, D-037).

```python
"""Notebook visibility and output rules (spec §5, plan Global Constraints). Pure: deps are injected."""

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import datetime
from typing import Protocol
from uuid import UUID

from api.platform.auth import CurrentUser

RESTRICTED = frozenset({"CONTROLLED", "SENSITIVE"})


@dataclass(frozen=True)
class NotebookRow:
    notebook_id: UUID
    owner_user_id: UUID
    owner_org_id: UUID
    visibility: str
    project_id: UUID | None
    deleted_at: datetime | None = None


@dataclass(frozen=True)
class AttachmentRow:
    dataset_id: UUID
    dataset_version_id: UUID
    slug: str
    access_level: str


class AccessDeps(Protocol):
    def is_active_member(self, project_id: UUID, user_id: UUID) -> bool: ...
    def is_visible(self, ctx: CurrentUser, dataset_id: UUID) -> bool: ...
    def can_read_data(self, ctx: CurrentUser, dataset_id: UUID) -> bool: ...


def can_edit(user: CurrentUser, nb: NotebookRow) -> bool:
    return nb.deleted_at is None and nb.owner_user_id == user.user_id


def can_view(user: CurrentUser, nb: NotebookRow, attachments: Sequence[AttachmentRow], deps: AccessDeps) -> bool:
    if nb.deleted_at is not None:
        return False
    if nb.owner_user_id == user.user_id or user.is_platform_admin:
        return True
    if nb.visibility == "PROJECT":
        return nb.project_id is not None and deps.is_active_member(nb.project_id, user.user_id)
    if nb.visibility == "DATASET_PUBLIC":
        return bool(attachments) and all(deps.is_visible(user, a.dataset_id) for a in attachments)
    return False


def outputs_visible(user: CurrentUser, attachments: Sequence[AttachmentRow], deps: AccessDeps) -> bool:
    return all(deps.can_read_data(user, a.dataset_id) for a in attachments if a.access_level in RESTRICTED)
```

```python
"""Notebook HTML: sanitize the runner's nbconvert output and serve it with a sandbox CSP (spec §6 step 3-4)."""

import copy
import html as html_lib
import re
from typing import Any

import nh3

_TAGS = {
    "a", "abbr", "b", "blockquote", "br", "caption", "code", "col", "colgroup", "dd", "del", "details", "div", "dl",
    "dt", "em", "figcaption", "figure", "h1", "h2", "h3", "h4", "h5", "h6", "hr", "i", "img", "ins", "kbd", "li",
    "main", "mark", "ol", "p", "pre", "q", "s", "samp", "section", "small", "span", "strong", "style", "sub",
    "summary", "sup", "table", "tbody", "td", "tfoot", "th", "thead", "tr", "u", "ul", "var", "body", "head",
    "html", "title", "meta",
}
_ATTRS = {
    "*": {"class", "id", "title", "lang", "dir"},
    "a": {"href"},
    "img": {"src", "alt", "width", "height"},
    "td": {"colspan", "rowspan", "align"},
    "th": {"colspan", "rowspan", "align", "scope"},
    "col": {"span"},
    "meta": {"charset"},
}
_SAFE_IMG = re.compile(r"^data:image/(png|jpeg|gif|svg\+xml);base64,[A-Za-z0-9+/=\s]+$")

RENDER_HEADERS = {
    "Content-Security-Policy": "sandbox; default-src 'none'; img-src data:; style-src 'unsafe-inline'; font-src data:",
    "X-Content-Type-Options": "nosniff",
    "Cross-Origin-Resource-Policy": "same-origin",
    "Referrer-Policy": "no-referrer",
    "Cache-Control": "private, no-store",
}


def _attribute_filter(tag: str, attr: str, value: str) -> str | None:
    if tag == "img" and attr == "src":
        return value if _SAFE_IMG.match(value) else None
    if tag == "a" and attr == "href":
        return value if value.startswith(("https://", "http://", "#")) else None
    return value


def sanitize_html(html: str) -> str:
    return nh3.clean(
        html,
        tags=_TAGS,
        clean_content_tags={"script", "iframe", "object", "embed", "svg", "math", "form", "noscript", "template"},
        attributes=_ATTRS,
        attribute_filter=_attribute_filter,
        url_schemes={"http", "https", "data"},
        link_rel="noopener noreferrer nofollow",
        strip_comments=True,
    )


def strip_outputs(ipynb: dict[str, Any]) -> dict[str, Any]:
    nb = copy.deepcopy(ipynb)
    for cell in nb.get("cells", []):
        if cell.get("cell_type") == "code":
            cell["outputs"] = []
            cell["execution_count"] = None
        cell.pop("attachments", None)
    return nb


def _source(cell: dict[str, Any]) -> str:
    src = cell.get("source", "")
    return "".join(src) if isinstance(src, list) else str(src)


def code_only_html(ipynb: dict[str, Any]) -> str:
    parts = ['<html><head><meta charset="utf-8"><title>notebook</title></head><body><main class="nais-code-only">']
    for cell in ipynb.get("cells", []):
        kind = "markdown" if cell.get("cell_type") == "markdown" else "code"
        parts.append(f'<section class="cell {kind}"><pre>{html_lib.escape(_source(cell))}</pre></section>')
    parts.append("</main></body></html>")
    return "".join(parts)
```

`service/versions.py` rules:
- `put_draft`: owner only.
  - The JSON size (`len(json.dumps(...).encode())`) must be ≤ `notebook_draft_max_bytes`, else 422 field `ipynb` reason `TOO_LARGE`.
  - The body must look like nbformat 4 (`nbformat == 4`, `cells` is a list), else 422 reason `NOT_NOTEBOOK`.
  - Upsert into `notebook_drafts`, then bump `notebooks.updated_at`.
- `request_version`: owner only.
  - Needs a draft, else 409 `details.reason = "NO_DRAFT"`, and no QUEUED/RUNNING version, else 409 `RUN_IN_PROGRESS`. Take `SELECT ... FOR UPDATE` on the notebook row to serialize.
  - `seq = max(seq)+1`.
  - `image_tag` = `pinned_image_tag` if mode PINNED and set; else the newest ACTIVE image (Task 11 refines it; for now `settings.notebook_default_image_tag`).
  - `attachments_snapshot` = list of `{dataset_id, dataset_version_id, slug, version_label, access_level, manifest_sha256}`; also copy `source_ipynb`, `requirements` and `internet_enabled` at request time.
- `lease_next`:
  - picks the oldest version with `run_status='QUEUED'`, or `'RUNNING'` with `lease_until < now`, using `FOR UPDATE SKIP LOCKED`;
  - when `attempts >= 3` it sets FAILED / `RUNNER_LOST` and continues to the next candidate;
  - otherwise sets RUNNING, `lease_until = now + lease_seconds`, `attempts += 1`;
  - creates a RUN-kind session row (owner as user, `expires_at = lease_until`) and returns `NotebookRunLease`, with `files` = every VERIFIED file of every attached version (`CatalogQueryPort.get_version(...).files`) and `target = f"{slug}/{version_label}/{path}"`, `timeout_seconds = settings.notebook_run_timeout_seconds`;
  - attachments the owner can no longer read (`can_read_data` false at lease time) are **left out**. The run still proceeds, and the notebook code sees the folder missing.
- `complete`:
  - the version must be RUNNING, else 409; `html` is passed through `sanitize_html` before storing;
  - stores the result, `duration`, `packages` and `finished_at`, and ends the RUN session with `end_reason='USER'`;
  - emits `notebooks.version.saved.v1` with `dataset_version_ids` from the snapshot.
- `get_version` / `render` need `can_view`, else 404.
  - `outputs_hidden = not outputs_visible(user, snapshot attachments)`.
  - The render returns the stored sanitized HTML when outputs are visible and the run is SUCCEEDED/FAILED. Otherwise it returns `sanitize_html(code_only_html(strip_outputs(source_ipynb)))`.
  - A QUEUED/RUNNING version → 409 `RUN_IN_PROGRESS`.
  - Return `Response(content, media_type="text/html; charset=utf-8", headers=RENDER_HEADERS)`.
- `fork`: needs `can_view`, and the version must be SUCCEEDED/FAILED (else 409).
  - Creates a new PRIVATE notebook owned by the caller, with `owner_org_id` = caller org, `forked_from_version_id` set, and title `f"{title} (fork)"` truncated to 200.
  - Copies `environment_mode`, `pinned_image_tag` and `requirements`. `internet_enabled` stays false when the snapshot has a restricted dataset.
  - Copies the attachments of the snapshot even when the caller cannot read them. Those rows are written directly, bypassing the permission check, and the view reports `mountable=false`.
  - Draft = `result_ipynb` if outputs are visible to the caller, else `strip_outputs(source_ipynb)`.
  - Emits `notebooks.notebook.created.v1` with `forked_from_version_id`.

```python
"""Helpers available in every NAIS notebook: attached data lives read-only under /data/input/<slug>/<version>/."""

import os
from pathlib import Path

INPUT = Path(os.environ.get("NAIS_INPUT_DIR", "/data/input"))


def list_inputs() -> list[str]:
    if not INPUT.is_dir():
        return []
    return sorted(f"{d.name}/{v.name}" for d in INPUT.iterdir() if d.is_dir() for v in d.iterdir() if v.is_dir())


def input_path(slug: str) -> Path:
    versions = sorted(p for p in (INPUT / slug).iterdir() if p.is_dir()) if (INPUT / slug).is_dir() else []
    if not versions:
        raise FileNotFoundError(f"dataset '{slug}' is not attached or not readable for this notebook")
    return versions[-1]
```

`nais_jupyter/hooks.py`:

```python
"""Autosave to NAIS through the Hub bridge (spec §6 step 2). Runs inside the user container; the bridge is the only
NAIS endpoint reachable from the sandbox network."""

import json
import os
import re
import time
import urllib.request
from typing import Any

_LAST: dict[str, float] = {}
_NOTEBOOK = re.compile(r"(?:^|/)work/([0-9a-f-]{36})\.ipynb$")
MIN_INTERVAL = 30.0


def bridge_url() -> str:
    base = os.environ["JUPYTERHUB_SERVICE_PREFIX"].split("/user/")[0]  # e.g. /notebooks/
    host = os.environ.get("NAIS_BRIDGE_HOST", "http://notebook-hub:8000")
    return f"{host}{base.rstrip('/')}/services/nais-bridge/draft"


def post_save_hook(model: dict[str, Any], os_path: str, contents_manager: Any, **_: Any) -> None:
    if model.get("type") != "notebook":
        return
    m = _NOTEBOOK.search(os_path)
    if not m:
        return
    nid = m.group(1)
    now = time.monotonic()
    if now - _LAST.get(nid, 0.0) < MIN_INTERVAL:
        return
    _LAST[nid] = now
    with open(os_path, "rb") as fh:
        body = json.dumps({"notebook_id": nid, "ipynb": json.load(fh)}).encode()
    req = urllib.request.Request(bridge_url(), data=body, method="PUT", headers={
        "Content-Type": "application/json",
        "Authorization": f"token {os.environ['JUPYTERHUB_API_TOKEN']}",
    })
    try:
        urllib.request.urlopen(req, timeout=10).close()
    except OSError:
        contents_manager.log.warning("NAIS autosave failed; the workspace copy is kept")
```

```python
"""Container options for user notebook servers (plan Global Constraints "Sandbox"). Pure; no jupyterhub import."""

from dataclasses import dataclass, field
from typing import Any

NETWORK = "nais_nb"
ENABLED_PROFILES = {"cpu-small"}
_ALLOWED_HOST_KEYS = {
    "cap_drop", "security_opt", "read_only", "pids_limit", "nano_cpus", "mem_limit", "memswap_limit", "tmpfs",
    "runtime", "init",
}


class UnsafeSpawnOption(ValueError):
    pass


@dataclass(frozen=True)
class SpawnSpec:
    image: str
    host_config: dict[str, Any]
    volumes: dict[str, dict[str, str]]
    environment: dict[str, str]
    network_name: str = NETWORK
    cmd: list[str] = field(default_factory=lambda: ["start-singleuser.py"])


def check_host_config(hc: dict[str, Any]) -> None:
    unknown = set(hc) - _ALLOWED_HOST_KEYS
    if unknown:
        raise UnsafeSpawnOption(f"host_config keys not allowed: {sorted(unknown)}")
    if hc.get("cap_drop") != ["ALL"] or hc.get("security_opt") != ["no-new-privileges:true"]:
        raise UnsafeSpawnOption("capabilities must be dropped and no-new-privileges set")
    if hc.get("read_only") is not True:
        raise UnsafeSpawnOption("root filesystem must be read-only")
    if hc.get("runtime") not in {"runc", "runsc"}:
        raise UnsafeSpawnOption("runtime must be runc or runsc")


def build_container_kwargs(policy: dict[str, Any], *, user_id: str, runtime: str, cache_dir: str) -> SpawnSpec:
    if policy["profile"] not in ENABLED_PROFILES:
        raise UnsafeSpawnOption(f"profile {policy['profile']} is not enabled")
    if policy["user_id"] != user_id:
        raise UnsafeSpawnOption("policy belongs to another user")
    mem = f"{int(policy['mem_gib'])}g"
    host_config: dict[str, Any] = {
        "cap_drop": ["ALL"],
        "security_opt": ["no-new-privileges:true"],
        "read_only": True,
        "pids_limit": 512,
        "nano_cpus": int(float(policy["cpu"]) * 1_000_000_000),
        "mem_limit": mem,
        "memswap_limit": mem,
        "tmpfs": {"/tmp": "size=1g", "/home/jovyan/.local": "size=2g"},
        "runtime": runtime,
        "init": True,
    }
    check_host_config(host_config)
    env = {
        "NAIS_NOTEBOOK_ID": policy["notebook_id"],
        "NAIS_SESSION_ID": policy["session_id"],
        "NAIS_NOTEBOOK_PATH": policy["notebook_path"],
        "NAIS_REQUIREMENTS": policy["requirements"],
        "NAIS_DOWNLOAD_ALLOWED": "1" if policy["download_allowed"] else "0",
    }
    if policy["internet_enabled"]:
        env |= {"HTTPS_PROXY": "http://nb-egress:3128", "HTTP_PROXY": "http://nb-egress:3128",
                "NO_PROXY": "pypi-mirror,notebook-hub"}
    volumes = {
        f"nais-nb-home-{user_id}": {"bind": "/home/jovyan/work", "mode": "rw"},
        f"{cache_dir.rstrip('/')}/sessions/{policy['session_id']}": {"bind": "/data/input", "mode": "ro"},
    }
    return SpawnSpec(image=policy["image"], host_config=host_config, volumes=volumes, environment=env)
```

Key code — `loader.py`:

```python
"""Content-addressed, read-only data cache for notebook sessions (spec §3 데이터 로더)."""

import hashlib
import os
import shutil
from collections.abc import Callable, Iterator
from dataclasses import dataclass
from pathlib import Path, PurePosixPath
from typing import Any


class ChecksumMismatch(RuntimeError):
    pass


@dataclass(frozen=True)
class Stats:
    files: int
    bytes: int


def _safe_target(target: str) -> PurePosixPath:
    p = PurePosixPath(target)
    if p.is_absolute() or "//" in target or any(part in ("..", "") for part in p.parts) or len(p.parts) < 3:
        raise ValueError(f"unsafe target {target!r}")
    return p


def materialize(session: dict[str, Any], cache: Path, fetch: Callable[[str, str], Iterator[bytes]]) -> Stats:
    blobs = cache / "blobs"; blobs.mkdir(parents=True, exist_ok=True)
    root = cache / "sessions" / session["session_id"]
    total = 0
    for f in session["files"]:
        rel = _safe_target(f["target"])
        blob = blobs / f["sha256"]
        if not blob.exists():
            tmp = blobs / f".{f['sha256']}.part"
            digest = hashlib.sha256()
            with open(tmp, "wb") as out:
                for chunk in fetch(f["file_id"], session["session_id"]):
                    digest.update(chunk); out.write(chunk)
            if digest.hexdigest() != f["sha256"]:
                tmp.unlink(missing_ok=True)
                raise ChecksumMismatch(f["file_id"])
            os.chmod(tmp, 0o444)
            os.replace(tmp, blob)
        dest = root / rel
        dest.parent.mkdir(parents=True, exist_ok=True)
        if not dest.exists():
            os.link(blob, dest)
        total += f["size_bytes"]
    return Stats(files=len(session["files"]), bytes=total)


def remove_session(cache: Path, session_id: str) -> None:
    shutil.rmtree(cache / "sessions" / session_id, ignore_errors=True)


def sweep_cache(cache: Path, cap_bytes: int) -> int:
    blobs = sorted((p for p in (cache / "blobs").glob("*") if not p.name.startswith(".")), key=lambda p: p.stat().st_atime)
    used = sum(p.stat().st_size for p in blobs)
    removed = 0
    for blob in blobs:
        if used <= cap_bytes:
            break
        if blob.stat().st_nlink > 1:  # linked by a live session tree
            continue
        used -= blob.stat().st_size
        blob.unlink(); removed += 1
    return removed
```
